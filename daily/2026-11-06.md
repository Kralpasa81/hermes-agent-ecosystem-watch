# 2026-11-06

## Hermes / Hermes-adjacent
- **Hermes Agent v0.23.0 — "The Hearth Release" (Nov 5, 2026).** The flagship release that fully documents v0.22.1–v0.22.7. Since v0.22.0: ~10,080 commits · ~1,950 merged PRs · ~8,720 files changed · ~850 issues closed · 666 contributors. Headline items:
  - **Desktop workspace in a browser tab** — the new Webapp serves the full Desktop workspace from your own gateway (same chats, Group Chats, plugins, settings), on your network or behind a public URL with sign-in. Off by default (`webapp.enabled`); ships in Docker and Nix. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.0))
  - **One gateway owns every conversation** — CLI, TUI, Desktop, editors (ACP), messaging bots, and cron now attach to a single gateway per machine as clients, ending messages written twice or lost between surfaces; a queued prompt can be steered/edited from Desktop without running twice.
  - **Pictures in the terminal** — pasted images and tool screenshots render inline in the CLI/TUI (kitty, Ghostty, iTerm2, WezTerm, Konsole; colored blocks elsewhere).
  - **/rewind** — Esc×2 or `/rewind` to edit-and-resend or fork a new session from an earlier message; `/new` can start while a turn is still running.
  - **Every machine in one Desktop window** — all gateways stay connected at once (instant SSH/remote switching), terminal tabs run on their host, Group Chats mix bots across machines.
  - **Group Chats that run themselves** — a lead bot or automatic router picks who answers an unnamed message; scheduled jobs post into rooms; rooms keep a purpose and shared notes; live per-bot status ("scout · terminal · 7s").
  - **Price tags and spend limits for paid tools** — paid MCP tools declare per-call cost; the approval prompt shows price + running total, and Hermes asks before going over the chat's limit, even in YOLO mode.
  - **Plugins that keep themselves current** — `hermes plugins update`, an opt-in Auto-update switch, holds for breaking updates, catalog grown ~600 → 1,050+ entries, and a new Verified tier for vendor-built plugins.
  - **New official plugins, smaller core** — Meshy (text/image→3D), ElevenLabs Music & Sound Effects, X Chat, REA (reverse engineering), and a bubblewrap sandbox are one-command installs; Camofox, `mcp-serve`, the agent importers, and Singularity moved out of core into self-installing plugins.
  - **Pluggable delegation** — `/delegation` or the `advanced-delegation` plugin routes each subagent task to a named model or separate profile.
  - **Lighter and faster** — recurring cron jobs share a prompt cache, one-shot runs send ~1,570 fewer prompt tokens per call, `patch`/`write_file` return in milliseconds with LSP on, and long-lived gateways release closed sessions' memory (a ~35k-cron-run store's Desktop refresh dropped from 121 s to instant).
  - **Leaner skills you can lock** — built-in skills 58 → 44 (Word/PowerPoint/Excel merged into `microsoft-office`); `hermes curator lock` stops autonomous rewrites of hand-curated skills, even in YOLO mode.
  - Also: password-manager plugins hand the browser only your logins (without seeing anyone else's), the browser vault key can live in the OS keychain, and you can **cancel a running cron job** from CLI/Desktop/API/the agent itself, with a per-job missed-run policy.
