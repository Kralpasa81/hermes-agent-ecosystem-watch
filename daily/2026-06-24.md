# 2026-06-24

## Hermes / Hermes-adjacent

- **Hermes Agent latest tagged release remains `v0.17.0` / `v2026.6.19` (“The Reach Release”).** No newer tagged release was found today, so this remains the current public release baseline. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Browser-tool resolution now validates that `agent-browser` is actually runnable, not only present on `PATH`.** This is a high-signal reliability fix for environments where an update can leave a dangling global symlink that `which` still sees but browser tools cannot execute. Source: https://github.com/NousResearch/hermes-agent/commit/3c75e115712f2af2cabdfbbe3a7033ea486a697d
- **Hermes docs now stop recommending direct `pip install`; the supported install path is the managed curl installer.** This matters for packaging clarity because the installer provisions an isolated `uv` environment instead of relying on system Python state. Source: https://github.com/NousResearch/hermes-agent/commit/a911bcda18cf83273d0aabd3e67adb2206436e60
- **New Claude / Anthropic OAuth logins were fixed after the token endpoint moved to `platform.claude.com`.** The initial code-exchange path now tries the live token host, restoring new OAuth credential setup for Claude-backed Hermes workflows. Source: https://github.com/NousResearch/hermes-agent/commit/2ee6449fe51d8feec4942d1b05f876c6631db3db
- **Gateway and messaging reliability improved on main.** Notable items include launchd-aware `/restart` service detection on macOS, Telegram command-menu priority / higher default menu capacity so skills stay visible, mid-stream Telegram overflow clipping, interrupt-time tool-call-sequence closure, and Bedrock delegation routing via `target_model`. Sources: https://github.com/NousResearch/hermes-agent/commit/abc3662bf6076045e4d4dc1e14a74cb35d69b86e60, https://github.com/NousResearch/hermes-agent/commit/dbe14ce35d9cb087ae9fe3e3f166f6c475297e25, https://github.com/NousResearch/hermes-agent/commit/d4be583d986f7bcca4f8414fd21ef9e34b18c948, https://github.com/NousResearch/hermes-agent/commit/73a20a6ad62b678d69335ef3a352ccf9ab85167b, https://github.com/NousResearch/hermes-agent/commit/81d2dc5d0f94268cda8306656d435562ae86a944, https://github.com/NousResearch/hermes-agent/commit/284d06cabfb5f19051c83320115fde74d9e344c1

## Broader AI agent ecosystem

- **Claude Code `v2.1.187` shipped as the latest stable release found today.** The strongest signals are `sandbox.credentials` protection for credential files / secret environment variables, organization model restrictions across model selectors and `ANTHROPIC_MODEL`, a default abort for remote MCP tool calls that hang for 5 minutes, structured-output loop fixes, background-agent stuck-state fixes, subagent depth tracking, and automatic cleanup of leaked agent worktree registrations. Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.187
- **GitHub Copilot CLI’s redesigned terminal interface is generally available.** It adds tabbed terminal browsing for issues / PRs / gists, guided in-session MCP server setup via `/mcp add` and `/mcp search`, skill/plugin/settings management from the TUI, and accessibility improvements. Source: https://github.blog/changelog/2026-06-23-copilot-cli-new-terminal-interface-is-generally-available/
- **GitHub Copilot app added BYOK model-provider support.** Users can connect OpenAI, Azure OpenAI, Microsoft Foundry, Anthropic, LM Studio, Ollama, or OpenAI-compatible endpoints, with API keys stored in the local OS keychain. Source: https://github.blog/changelog/2026-06-23-github-copilot-app-support-for-byok
- **MCP Enterprise-Managed Authorization is stable.** This is a strong interoperability / governance signal because organizations can centrally authorize MCP server access via an IdP, reducing repeated per-server OAuth prompts and improving auditability. Source: https://blog.modelcontextprotocol.io/posts/enterprise-managed-auth/
