# 2026-06-29

## Hermes / Hermes-adjacent

- **Main-branch Desktop/Dashboard decoupling:** Hermes merged a shared WebSocket / JSON-RPC layer and introduced clearer Desktop-vs-dashboard separation around `hermes serve`. This is meaningful for remote/headless operation because Desktop clients should depend less on launching the dashboard surface directly. Source: https://github.com/NousResearch/hermes-agent/commit/388268ecde085a22c15474fea1723db161a930da
- **Desktop terminal persistence:** Desktop terminal tabs and scrollback can now persist and restore across relaunches, improving continuity for GUI-driven coding and operations work. Source: https://github.com/NousResearch/hermes-agent/commit/fb0644fbc2a56d7b76f0f2856cca989314a05e2a
- **External cron provider status fix:** `hermes cron status` was adjusted so external schedulers such as Chronos do not get misleading “gateway not running” warnings just because they do not run the built-in ticker heartbeat loop. This directly affects scale-to-zero and webhook-fired scheduled jobs. Source: https://github.com/NousResearch/hermes-agent/commit/0943e2a2720fd2b7eb5aee19c3bad0d495e5450a
- **Skills path-containment hardening:** Hermes replaced string-prefix path checks with strict path containment for skills, a practical safety/correctness improvement around skill file access. Source: https://github.com/NousResearch/hermes-agent/commit/313a8c68332e126e6b5b831877da3d8c2dd3f72f
