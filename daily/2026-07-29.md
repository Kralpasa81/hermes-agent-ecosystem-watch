# 2026-07-29

## Hermes / Hermes-adjacent

- **Streaming TTS lands as a real cross-provider latency capability.** A new opt-in streaming-audio adapter seam on `BasePlatformAdapter` lets voice-capable gateway platforms (LiveKit, Discord voice, future adapters) consume LLM output as streaming PCM audio before the full response completes, cutting perceived voice latency from ~2–3.5s to ~500–800ms. Gemini (SSE) and xAI (WebSocket) streaming providers were added alongside the existing ElevenLabs/OpenAI streamers, plus a new `tts.streaming.provider` knob to pin one provider or let it auto-walk a priority list. All existing adapters default to unsupported/no-op, so this ships without breaking anything.
  https://github.com/NousResearch/hermes-agent/commit/3a4aa2f8e6, https://github.com/NousResearch/hermes-agent/commit/bc4dcb1b02
- **Voice mode's stop-phrase handling closes a real gap: it now works consistently everywhere, spoken or typed.** Yesterday's stop-phrase feature had a hole — the force-transcribe path silently discarded a spoken stop phrase, so with `auto_restart=False` some hands-free conversations never actually ended, and a *typed* stop phrase wasn't caught at all. Now covers CLI, TUI, and desktop, spoken and typed, and a configured stop phrase always wins over the Whisper hallucination filter (e.g. "bye" as both a stop phrase and a hallucination-blocklist entry).
  https://github.com/NousResearch/hermes-agent/commit/ba13132298
- **Speech-to-text becomes a first-class configurable subsystem.** Full STT model configurability landed in both `hermes tools` and the GUI (new dashboard STT dropdowns), OpenAI's `gpt-transcribe` model is now supported, and a real accuracy bug — faster-whisper "silence hallucinations" — was fixed at the source rather than patched around.
  https://github.com/NousResearch/hermes-agent/commit/96bf65a6f7, https://github.com/NousResearch/hermes-agent/commit/c80acad5b7, https://github.com/NousResearch/hermes-agent/commit/805c1c340c, https://github.com/NousResearch/hermes-agent/commit/bf8004e3a8
- **The dual-stack webhook bind fix (previously shipped for LINE) is extended to five more messaging integrations.** WeCom, Microsoft Graph, WhatsApp Cloud, Teams, and Telegram webhook listeners were defaulting their bind host to `0.0.0.0`, making them unreachable over IPv6-only private networks (e.g. Fly.io 6PN). Same root cause, same fix pattern, now closed across the board.
  https://github.com/NousResearch/hermes-agent/commit/2c771be406
- **Hermes×Buzz (Nostr) integration reaches a documented, three-path state.** A dependency-free Nostr signing module (NIP-42 auth, BIP-340 Schnorr signing) and a persistent WebSocket inbound transport (live DM discovery via membership events, resume-on-reconnect, automatic fallback to polling) now sit alongside a new unified integration doc covering Desktop managed runtime, the `buzz-acp` relay bridge, and the native gateway platform. Buzz is Hermes's first native integration with a decentralized-social/messaging protocol.
  https://github.com/NousResearch/hermes-agent/commit/07e931fcb4, https://github.com/NousResearch/hermes-agent/commit/21c7b806a3, https://github.com/NousResearch/hermes-agent/commit/219c04a341
- No new tagged release since **v0.19.0 "Quicksilver"** (Jul 20). Today's work is a genuine feature/reliability day (streaming TTS, voice stop-phrase correctness, STT configurability, dual-stack webhook fixes, Buzz), not routine churn.

## Broader AI agent ecosystem

- **The MCP 2026-07-28 specification has gone live.** `modelcontextprotocol.io/specification/latest` now 307-redirects to `/specification/2026-07-28` (as of yesterday's check it still pointed at `2025-11-25`). This is the largest MCP revision since launch: a stateless HTTP core (no more `initialize`/session stickiness — a plain round-robin load balancer now suffices), MCP Apps (server-rendered UIs), the Tasks extension for long-running work, OAuth/OIDC-aligned authorization, and a formal 12-month deprecation policy. It is a confirmed **breaking change** for existing MCP client/server implementations.
  https://modelcontextprotocol.io/specification/2026-07-28, https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **OpenAI Codex CLI ships stable `rust-v0.146.0` (Jul 29)** after a week of alpha churn: named/pinnable sessions with side conversations, thread forking with paginated history, Code Mode over WebSocket to remote hosts, standalone web search for custom model providers, executor-provided skill discovery — and, notably, **Agent Plugins gain workspace publishing plus new marketplaces for Amazon Bedrock and Claude Code**, a genuine cross-vendor plugin-interoperability move rather than a Codex-only feature.
  https://github.com/openai/codex/releases/tag/rust-v0.146.0
- **Grok 4.5 rolled out in GitHub Copilot (Jul 28)** across Copilot surfaces — a model-menu expansion, not a new capability class.
  https://github.blog/changelog/2026-07-28-grok-4-5-is-now-available-in-github-copilot
- No new Claude Code release since `2.1.220` (Jul 25); no Anthropic news item since Jul 27 relevant to coding agents.

## Note

Bugün hem Hermes tarafında hem daha geniş ekosistemde gerçek anlamda önemli gelişmeler var. Hermes'te en dikkat çekici değişiklik streaming TTS: gateway'e opt-in bir streaming-audio adapter seam'i eklendi (LiveKit, Discord voice gibi platformlar için), algılanan ses gecikmesini ~2-3.5 saniyeden ~500-800 milisaniyeye düşürüyor; Gemini ve xAI streaming provider'ları eklendi, ElevenLabs/OpenAI zaten mevcuttu. Ayrıca dün eklenen "stop phrase" özelliğinde gerçek bir açık kapatıldı — force-transcribe yolunda stop phrase sessizce göz ardı ediliyordu ve typed stop phrase hiç yakalanmıyordu; artık CLI/TUI/desktop'ta, sesli/yazılı her yerde tutarlı çalışıyor. STT (speech-to-text) tam yapılandırılabilir hale geldi (GUI dropdown'ları, OpenAI gpt-transcribe desteği, faster-whisper halüsinasyon düzeltmesi). Dual-stack webhook bind düzeltmesi (önceden LINE için yapılmıştı) WeCom/MSGraph/WhatsApp Cloud/Teams/Telegram'a genişletildi. Ve Hermes×Buzz (Nostr protokolü) entegrasyonu üç yolla (Desktop, buzz-acp relay, native gateway platform) belgelenmiş, daha eksiksiz bir hâle geldi — Hermes'in ilk native decentralized-social/messaging platform entegrasyonu. Yeni bir sürüm etiketi yok (v0.19.0 "Quicksilver" hâlâ Jul 20'den itibaren en güncel) ama bugünkü commit'ler gerçek özellik/güvenilirlik işi, rutin UI cilası değil. Broader ecosystem'de bugün iki gerçek gelişme var: MCP'nin 2026-07-28 final spec'i artık canlı (modelcontextprotocol.io/specification/latest artık 2026-07-28'e yönlendiriyor — dün hâlâ 2025-11-25'teydi), protokolün lansmandan sonraki en büyük revizyonu ve mevcut implementasyonlar için kırıcı bir değişiklik; ve OpenAI Codex CLI stable `0.146.0`'ı yayınladı, en dikkat çekici kısmı Agent Plugins marketplace'inin Amazon Bedrock ve Claude Code'a genişletilmesi (gerçek cross-vendor interoperability sinyali). GitHub Copilot'a Grok 4.5 geldi (Jul 28) ama bu bir model menüsü genişlemesi, yeni bir kapasite değil. Claude Code (`2.1.220`, Jul 25) tarafında bugün yeni bir şey yok.
