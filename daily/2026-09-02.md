## Broader AI agent ecosystem

- **Claude Fable 5.1 GA in GitHub Copilot (Sep 1)**  
  Anthropic's Mythos-class model — designed for long-horizon, autonomous coding and knowledge-work tasks — is now generally available in GitHub Copilot (Pro+, Max, Business, Enterprise). Available across VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI, Copilot coding agent, GitHub.com, and GitHub Mobile.  
  **Data retention note:** Fable 5.1 requires data retention by default (Anthropic runs safety classifiers on retained prompts/outputs; not used for training). ZDR access available for eligible enterprises under a time-bound EFS exemption.  
  Source: https://github.blog/changelog/2026-09-01-claude-fable-5-1-generally-available-in-github-copilot

- **Copilot code review can now approve pull requests (Sep 1, public preview)**  
  GitHub Copilot's code review can now emit a real PR approval that counts toward required-approvals rules (off by default; configurable at enterprise / org / repo level, down to specific file paths). Each review includes an approval assessment in the overview comment. Approval is dismissed on new pushes, same as a human reviewer's.  
  Available to Copilot Pro, Pro+, Max, Business, and Enterprise.  
  Source: https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests

- **GitHub Copilot in VS Code — August 2026 releases (Aug 31, VS Code v1.132–v1.135)**  
  Agent sessions: arrange chats side by side, `/btw` opens a side-chat sharing the primary cache, continue external Copilot/Claude sessions from other apps, Agent Host connects multiple VS Code windows to the same session. Agent Plugins 1.0 standard enables portable customizations across compatible clients. Experimental `/rubber-duck` asks a complementary model to surface missed details. Integrated browser: comment on HTML elements for targeted UI feedback. Multi-language dictation with shell-aware terminal cleanup.  
  Source: https://github.blog/changelog/2026-08-31-github-copilot-in-vs-code-august-2026-releases/

- **Databricks Big Book of AgentOps released (Sep 2)**  
  Databricks published a free production playbook for AI agents today: architecture patterns, a seven-phase project lifecycle, evaluation/feedback loops, DevOps-adapted practices for nondeterministic systems, governance, cost management, and a stakeholder RACI matrix. Covers anti-patterns and field-tested examples (FactSet +44% accuracy, DXC −30% TCO, ICE 96% SQL execution match).  
  Source: https://www.databricks.com/blog/announcing-databricks-big-book-agentops
