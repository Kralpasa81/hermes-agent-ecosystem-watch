## Broader AI agent ecosystem
- **DeepSeek open-sources "Super-agent" — a prototype autonomous coding agent (WeChat post Oct 31, widely reported Nov 1).** DeepSeek's Harness team released an MIT-licensed research prototype ([`deepseek-ai/dsh-superagent-prototype`](https://github.com/deepseek-ai/dsh-superagent-prototype)) that proactively watches developer group chats (GitHub, optional Feishu), spots bugs without being summoned, reproduces them, and prepares a fix in the background — submitting a change for human review only when it finds a viable solution. It runs on DeepSeek Harness and is explicitly framed as an architectural exploration, not an official product, positioned squarely against Anthropic's Claude Code. ([Bloomberg](https://bloomberg.com/news/articles/2026-11-01/deepseek-drops-enhanced-coding-agent-with-aim-to-rival-anthropic), [TNW](https://thenextweb.com/news/deepseek-open-sources-super-agent-a-prototype-autonomous-coding-agent))
- **Perplexity launches Teammates — always-on agents for ongoing work (Nov 6).** Each Teammate runs on its own VM (desktop + browser) and draws continuity from the user's existing Perplexity projects, skills, and memory, targeting long-running multi-step work rather than one-off tasks. Requires the $200/month Max plan. Joins OpenAI Dots, Anthropic Duet, Meta Muse, and xAI Grok Bots in the always-on-agent category. ([Perplexity](https://www.perplexity.ai/hub/blog/teammates-are-agents-for-complex-ongoing-work), [The Decoder](https://the-decoder.com/perplexity-now-has-its-own-always-on-ai-agent/))
- **OpenAI releases GPT-6 Cyber (Nov 5).** A specialized cybersecurity model (a GPT-6 Astra variant) now rated Critical under OpenAI's Preparedness Framework: 48.5% on ExploitGym (vs 32.1% for GPT-5.6 Cyber), 948 Linux privilege-escalation exploits, and 81 previously unknown high-severity Firefox vulnerabilities, while staying in-scope 99.93% of the time without a deployment prompt. Gated to approved Daybreak Red customers; notable here mainly as an agent-scoping/safety milestone and for Codex Security Cloud, not a general coding-agent tool. ([OpenAI](https://openai.com/index/introducing-gpt-6-cyber/))
