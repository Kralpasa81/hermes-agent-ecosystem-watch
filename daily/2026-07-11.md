# 2026-07-11

## Hermes / Hermes-adjacent

- Hermes Agent remains at **v0.18.2 (v2026.7.7.2)** — the latest stable tagged release, shipped July 7. No new tagged release since then.
  - Active development continues on `main` (post-v0.18.0 window). Full curated release notes for this cycle are expected with **v0.19.0**.
  - `hermes update` or `pip install -U hermes-agent` to stay current.
  - Source: https://github.com/NousResearch/hermes-agent/releases

- **Hermes session management upgrade** (landed ~July 6 in `main`, confirmed via @NousResearch / @Teknium on X).
  - `hermes sessions prune` and `hermes sessions archive` now accept a broad set of filters (by age, platform, tag, status, etc.), letting users clean up or archive session DB selectively without losing strategically important sessions.
  - This is a UX-level quality-of-life improvement for long-running Hermes deployments where session DBs accumulate over time.
  - Source: https://x.com/NousResearch, https://hermes-agent.nousresearch.com/docs/user-guide/sessions

## Broader AI agent ecosystem

- **OpenAI GPT-5.6 (Sol / Terra / Luna) lands in GitHub Copilot** (July 9).
  - Three variants now available across Copilot plans: Sol (highest reasoning ceiling, Pro+/Max/Business/Enterprise), Terra (balanced default, all plans ≥ Pro), Luna (lightweight/cost-efficient, all plans ≥ Pro).
  - Billed at provider list pricing under usage-based billing. Enterprise/Business admins must enable the policy (off by default).
  - Available in VS Code, VS, JetBrains, Xcode, Eclipse, Copilot CLI, Copilot app, GitHub.com, and GitHub Mobile. Rollout is gradual.
  - Source: https://github.blog/changelog/2026-07-09-openais-gpt-5-6-sol-terra-and-luna-are-now-available-in-github-copilot/

- **GitHub Copilot in VS Code — June 2026 release summary** (posted July 8).
  - Covers VS Code v1.123–v1.127. Key changes: agentic browser tools GA (agents can navigate, screenshot, and validate web apps inside VS Code); parallel agent sessions (run side-by-side, multi-chat within one session); full session cost visibility (total + subagent credit usage); model provider discovery from the Marketplace; Autopilot improvements (better task-completion judgment, less manual steering); session sync and history across machines; 1M context windows for compatible Anthropic/OpenAI models; MCP OAuth credential storage; enterprise MDM-managed Copilot settings.
  - Source: https://github.blog/changelog/2026-07-08-github-copilot-in-visual-studio-code-june-2026-releases/

- **MCP 2026-07-28 specification** — the RC validation window continues. Final spec ships **July 28**. Hermes MCP skill/tool authors should be actively reviewing the stateless HTTP changes.
  - Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
