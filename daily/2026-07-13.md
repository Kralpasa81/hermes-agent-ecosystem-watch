- Real correctness fixes landed on `main` (Jul 12–13) touching the surfaces most operators use directly — dashboard config and Desktop settings:
  - **Dashboard `approvals.mode` selector fixed** — the web UI schema showed `['ask', 'yolo', 'deny']`, none of which match the real config values, leaving `smart` mode entirely unreachable from the dashboard. Corrected to `['manual', 'smart', 'off']` with a regression test added. Fixes #31925.
    https://github.com/NousResearch/hermes-agent/commit/da6d6164bafbf4de80a3f99098e40f12b3e2fa63
  - **Desktop Fallback Models editor rebuilt** — Settings → Model was rendering the `fallback_providers` list through the generic list field, stringifying each `{provider, model}` entry as `[object Object]`. Replaced with a dedicated provider+model row editor that reads/writes the structured chain correctly.
    https://github.com/NousResearch/hermes-agent/commit/21781d54ecb3da1d53a608f46eea64bc67f6c225
  - **Windows folder-picker paths bridged for WSL backends** on Desktop (merge of #63105, superseding long-open #43809) — fixes folder selection for users running the Desktop app against a WSL backend.
    https://github.com/NousResearch/hermes-agent/commit/e589b739ca70eba00aa90fd3d0228bada00dbf8f

- These are unreleased/main-branch fixes, not yet in a tagged version — worth tracking now since they resolve config and Desktop UX bugs that were silently breaking `smart` approval mode and fallback-model configuration.

## Broader AI agent ecosystem

- **Anthropic extended plan-included Claude Fable 5 access a second time** — announced in the early hours of July 13 via the official @claudeai account, after the July 12 cutoff had already passed. Plan-included Fable 5 access on Pro/Max/Team/eligible Enterprise plans, and Claude Code's 50% higher weekly rate limits, now run through **July 19, 2026**. This is the second extension in six days (original cutoff was July 7). Mechanics are unchanged: up to 50% of weekly usage limits on Fable 5, drawn from the same pool as other models; after that, prepaid usage credits at $10/$50 per M tokens in/out.
  - Relevance: directly affects Claude Code users and any workflow standardizing on Fable 5 — availability keeps shifting on roughly weekly notice, which is a real planning risk for teams building on it.
  - Sources: https://www.anthropic.com/news/redeploying-fable-5, https://support.claude.com (help center, updated Jul 13)

- **OpenAI Codex CLI catch-up (Jul 7–13)**: several releases shipped since the last tracked baseline (0.142.5).
  - `0.143.0` (Jul 7–8): remote plugins enabled by default (npm marketplace sources, richer catalog rows); Codex can now route auth/Responses API traffic through macOS/Windows system proxies (PAC/WPAD); Amazon Bedrock gained GPT-5.6 Sol/Terra/Luna with `max` reasoning effort; MCP tools now use tool search by default.
  - `0.144.0` (Jul 9): new `writes` app-approval mode (auto-allow declared read-only actions, prompt only on writes); MCP tools can request auth interactively without an experimental flag; Ultra reasoning effort now warns when high multi-agent concurrency could burn usage fast.
  - `0.144.2` (Jul 13): reverted a Guardian auto-review prompting regression back to the previous policy/request format.
  - Source: https://github.com/openai/codex/releases, https://developers.openai.com/codex/changelog
