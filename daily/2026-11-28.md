# 2026-11-28

## Hermes / Hermes-adjacent
- **Hermes Agent v0.23.5 (stable)** — released today (tagged Nov 27, published Nov 28 03:20 UTC). Rolls up **~338 PRs** since v0.23.4 into the CLI/installers, Microsoft Store, Docker, and Hermes Cloud (1,262 non-merge commits, 1,146 changed files, 338 merged PRs, 92 closed issues). Full curated notes still ship with v0.24.0; the release body lists the window's headline changes:
  - **CLI/TUI OSC 7577 program resume protocol** support.
  - **Idle gateway chats compact in the background on every route** (not just the compact-on-idle path).
  - `read_file` tails with a negative offset and lists directories; `search_files` reports when a content search is the whole answer.
  - **Bounded default-plugins preflight** before the local gateway starts (Desktop, Docker, and CLI).
  - **Plugin OAuth entries can pin their redirect URI**; the **Solstice provider moved to the stateless Interactions API**.
  - New plugin API surfaces: **turn origin, how a session was created, cron scheduling, gateway silence helpers**.
  - Dashboard "your dashboard is moving" notice; raw arrow keys work in the sessions and plugins pickers.
  - A long series of fixes keeping plugin work bound to the right profile when a profile is renamed, moved, or removed. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.5))
- This is the **second stable patch this week** (after v0.23.4 on Nov 24) and consolidates the mainline work flagged in yesterday's canary note — gateway stop/restart reliability, the `turn_origin` plugin API, and the Google Gemini/Solstice consolidation — into a stable release.

## Broader AI agent ecosystem
- **Google Workspace MCP servers + CLI reach GA (Nov 24).** Google made its hosted **Workspace MCP servers** (Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat, Tasks; Keep soon) and the **Workspace CLI** (`gwscli`) generally available, under free **Standard** / paid **Scaled** usage tiers. The policy change matters most: from **Feb 1, 2027**, AI agents must reach Workspace data via MCP or the CLI instead of calling Workspace REST APIs directly (technical enforcement). A major enterprise-platform push behind MCP as the standard agent-access path. ([announcement](https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html))
- **GitHub Copilot code review billing defaults to the organization (announced Nov 25, effective Dec 30).** Orgs/enterprises on Copilot Business/Enterprise that never picked a billing option will have licensed members' code reviews billed to the repository-owning org (instead of the member's entitlement) — provided AI Credits paid usage is on. A cost/governance change for Copilot code review. ([changelog](https://github.blog/changelog/2026-11-25-copilot-code-review-billing-will-default-to-the-organization))
- **MCP reference servers v2.5.0 security update (Nov 18).** Eight vulnerabilities across three servers; update `mcp-server-git` → `2026.11.18`, `@modelcontextprotocol/server-filesystem` → `2.4.0`, and `@modelcontextprotocol/server-everything` → `2.3.1`. ([releases](https://github.com/modelcontextprotocol/servers/releases))
- **Anthropic internal workflow signal (Nov 27).** Claude platform engineering lead Katelyn Lesse said ~80% of code submitted via AI agents now skips line-by-line human review (relying on testing/validation instead), and Anthropic has dropped traditional coding interviews in favor of AI-assisted system-design assessments. A signal of how the Claude team itself ships agent-generated code. ([Gate News](https://gate.com/news/detail/anthropic-rewrites-development-process-with-ai-agents-submitting-80-of-code-25903733))
