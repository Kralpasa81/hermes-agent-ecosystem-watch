## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but main-branch work was highly active again.** The strongest signals were approval hardening for sensitive files, SSL certificate fail-fast behavior, refusal/content-filter handling, richer file ingestion, Desktop notification/compaction polish, and runtime/search reliability fixes. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Sensitive local-file write protection was tightened.** Hermes now gates in-place edits to sensitive user files, detects absolute home shell-rc writes, and gates `cp`/`mv`/`install` into `~/.ssh`, credential, and shell-rc paths. Sources: https://github.com/NousResearch/hermes-agent/commit/2b67e96aec2aa2abd5e94b544cda8e564c75f9f5, https://github.com/NousResearch/hermes-agent/commit/abd69b811702281c5728638ec4fce7c0babeaedd, https://github.com/NousResearch/hermes-agent/commit/da28d5d113956dcf803d5cff552a120740a96a59
- **Provider/network failure handling became safer and more explicit.** Hermes added a fail-fast SSL CA certificate bundle guard across agent, gateway, and doctor paths, validates CA bundle paths before provider calls, runs the guard during agent initialization, and aligned guard docs / escape-hatch behavior. Sources: https://github.com/NousResearch/hermes-agent/commit/a218a0f1569cea01e217aad47af49ac61c2a8607, https://github.com/NousResearch/hermes-agent/commit/af5b52647265a42d81bbf5f5f2880e6ca5c9313b, https://github.com/NousResearch/hermes-agent/commit/dc90ca4e17404fb891073de958d23dbc872538f3, https://github.com/NousResearch/hermes-agent/commit/7aaae7acd0d6f80aba9fbe15324a1c907ec70c55
- **Model refusal and content-filter paths were cleaned up.** Hermes now surfaces model refusals instead of retrying them as generic errors, treats OpenRouter content-filter payloads as pass-through in the relevant transport path, only treats a refusal as terminal when it is the sole payload, and shares the content-policy-blocked result builder plus recovery hint. Sources: https://github.com/NousResearch/hermes-agent/commit/bb46bf8ce430152e0b0554bbd6c5644fed80d8ad, https://github.com/NousResearch/hermes-agent/commit/ab26541b9a1feaab728c86685ef89b06885f16de, https://github.com/NousResearch/hermes-agent/commit/12c84d6c77a6ecb754b9025a8e9f1a5e8233fc65, https://github.com/NousResearch/hermes-agent/commit/10bd01972b03659db25ad9365170f179d05aebe2
- **Hermes gained more practical input and reliability coverage.** The `read` tool path can now extract notebook and office documents, search keeps partial results on timeout, `execute-code` no longer waits on idle RPC accept before completion, bundled skill-update backup handling is crash-safe/idempotent, and atomic replace has a cross-device copy fallback. Sources: https://github.com/NousResearch/hermes-agent/commit/817f39231145bbb24eb57b8b2835cb00c91e87ed, https://github.com/NousResearch/hermes-agent/commit/1fa761f8ded58e652ff1ef8861cdfe9407f014be, https://github.com/NousResearch/hermes-agent/commit/8f278403d1214a4c482b9c79efb7d329ffd3eb8a, https://github.com/NousResearch/hermes-agent/commit/3581131e7de1560633c921b4782ea87dcbac3a9e, https://github.com/NousResearch/hermes-agent/commit/bf8effad023b275aca2ea4b674efc45f4ba7e88f
