# 2026-11-05

## Hermes / Hermes-adjacent
- **MCP consent transparency (mainline, Nov 5).** A merged commit makes each MCP consent row in Desktop show what it will actually run or contact before the user installs/enables/authorizes a server — a backend-built, scrubbed `launch` line (e.g. `Runs: npx -y ...` or `Connects to: https://...`) rendered under the row. Secret-valued flags (`--api-key=...`, `--token ...`), credential query params, URL userinfo, and long opaque path segments are redacted before display. A targeted MCP approval-surface hardening change; not yet in a stable release. ([commit](https://github.com/NousResearch/hermes-agent/commit/3dbb1303fe3d3cb69615a7b3a811ee9ecfe13446))
- **Desktop Plugins tab gains "Update all" + Auto-update (mainline, Nov 5).** A feature commit adds an "Update all" button and an Auto-update switch for the selected profile to the Plugins tab, backed by `plugins.manage update_all` / `auto_update`. Companion fixes make unattended updates respect `--ref` holds (pinned catalog installs held for rollback are skipped), re-check holds at the mutation boundary, and log a review line instead of a traceback on a widened pin. Also mainline only. ([commit](https://github.com/NousResearch/hermes-agent/commit/c91c57b1e2d85811119d6494b99c0ef50fd09a6f))
- _No new stable release today; v0.22.7 (Nov 3) remains the latest tag._

## Broader AI agent ecosystem
- **GitHub Copilot is now available in Xcode's coding assistant (Nov 4).** Public preview brings Copilot into Apple's built-in Xcode coding assistant, starting with Xcode 27.3 beta (macOS Tahoe 26.6+). The existing GitHub Copilot for Xcode extension remains a separate option; all Copilot plans are supported. ([changelog](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant))
- **GitHub Copilot reaches JetBrains Air (Nov 3).** Copilot is now available in JetBrains' Air IDE, extending Copilot's editor surface. ([changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air))
- **Anthropic Claude message threads (beta, Nov 2).** The Messages API can now keep a conversation on the server, so long agent loops send only new messages per request — smaller requests and a lower time-to-first-token — via the `message-threads-2026-08-12` beta header. A thread expires 5 minutes after its last request. ([release notes](https://platform.claude.com/docs/en/build-with-claude/message-threads))
- **Anthropic 2026 Usage Policy update (effective Nov 12).** Adds a consolidated "deceptive campaigns" section and, following the Model Hardware Standard preview, new requirements when models are connected to hardware that takes autonomous physical actions (a qualified operator must be able to observe and stop it; the equipment must hold a safe state if disconnected). Governance-relevant for autonomous agents. ([Anthropic](https://www.anthropic.com/news/2026-usage-policy-update))
