## Broader AI agent ecosystem

- **Anthropic says Fable 5 and Mythos 5 access must be suspended for all customers after a US government export-control directive.** Anthropic states the directive covers any foreign national and that, because of the order’s scope, it must disable these models for all customers to ensure compliance; it also says access to all other Anthropic models is not affected. This is a high-impact access/governance signal for Claude Code, Copilot model selection, provider routing, and teams that had started evaluating Fable/Mythos-class coding workflows. Source: https://www.anthropic.com/news/fable-mythos-access
- **Claude Code `2.1.176` focused on model-policy enforcement, remote-control correctness, background-agent durability, and Windows/Linux/tmux reliability.** Notable fixes include blocking alias model picks from redirecting to disallowed models via `ANTHROPIC_DEFAULT_*_MODEL`, preventing `/fast` from switching outside an allowlist, avoiding Remote Control model switches, improving background-agent search and daemon/session recovery, fixing path matching for hook `if` conditions, and improving Bedrock credential caching. Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- **GitHub Copilot code review gained stronger organization and content-governance controls.** GitHub added organization-level runner configuration for Copilot code review / Copilot cloud agent, support for Copilot content exclusions at repository/org/enterprise scope, and removed the previous 4,000-character limit for Copilot code review custom instruction files. Source: https://github.blog/changelog/2026-06-12-copilot-code-review-new-configurations-and-controls
- **GitHub Actions self-hosted runner minimum-version enforcement is worth tracking for agentic workflows that run inside Actions.** GitHub says self-hosted runners must be at least `2.329.0` to register/re-register and must stay within 30 days of new releases for job execution, with full enforcement starting July 31, 2026 for Enterprise Cloud with Data Residency and September 25, 2026 for Enterprise Cloud. Source: https://github.blog/changelog/2026-06-12-github-actions-minimum-version-enforcement-timeline-for-self-hosted-runners
