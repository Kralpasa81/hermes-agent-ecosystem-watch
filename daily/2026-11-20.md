## Hermes / Hermes-adjacent
- **Hermes Agent v0.23.3** (Nov 19) — stable patch rolling up ~370 PRs since v0.23.2 into the CLI/installers, Microsoft Store, Docker, and Hermes Cloud. Measured at commit `caafe5389ae`: 1,657 non-merge commits across 3,948 files, 370 merged PRs, 60 closed issues. Headline changes (undocumented until v0.24.0, per the tag): a **prompt-cache lifecycle controller** (warms the cache through long tool runs, compacts idle chats before the 1h cache expires, Nous Portal on the full 1h lifecycle, `prompt_caching.cache_ttl` defaulting to `auto`); **compaction now archives the tool results it drops** and the **proactive tool-result prune is on by default**; a **one-question first-run CLI setup** with the free tier included; **GPT-6.2 Astra and Sol (+ Pro) on OpenRouter and Nous Portal**; a "Waiting on teammates" strip above Bot Chat composers; the Linux AppImage agent payload run from a stable per-build copy; the storage layer split behind a persistence interface with its SQLite backend; dependency security bumps (oauthlib, opentelemetry, tornado); and a large batch of new plugin-catalog entries. Full curated notes ship with v0.24.0. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3))
