# 2026-07-28

## Hermes / Hermes-adjacent

- **A real MCP interoperability gap with Figma is closed.** Figma's `mcp.figma.com` OAuth registration endpoint is a `client_name` allowlist — Claude Code and Codex succeeded, Hermes Agent 403'd. Fix auto-sets `client_name` + `client_secret_post` for Figma hosts, threads the OAuth config through both login and add paths, forces interactive OAuth for `hermes mcp login` from non-TTY desktop shells, and ships a catalog entry. Verified end-to-end: `hermes mcp login figma` now surfaces 26 tools.
  https://github.com/NousResearch/hermes-agent/commit/1eb5ee1e
- **Desktop ships floating panes and a floatable composer — a genuine new UI capability, not a bug fix.** Chat surfaces can now pop their composer (and other panes) out of the fixed layout tree, with pure clamping/anchoring rules (48px grabbable edge margins, top bound below the titlebar, pin-top-left instead of inverting when a card outgrows the viewport, edge-riding on window resize). The geometry logic is DOM-free and directly testable. The SDK now exposes `FloatingAnchor` to plugins, so third-party surfaces can adopt the same floating behavior.
  https://github.com/NousResearch/hermes-agent/commit/6dd1c6c0, https://github.com/NousResearch/hermes-agent/commit/25ff7751
- **A gateway race that made queued messages behave unpredictably is closed.** Desktop's "run this after the current turn" queue promise broke on a millisecond settle race: a drain firing while the server was still unwinding the previous turn could land in the busy-submit path and get treated as a live-turn steer, redirect, or interrupt instead of a plain queued send — so force-sending a queued message felt like a dice roll. Queued drains now carry an explicit `queued:true` flag that the gateway's busy path always honors, covered by tests on both the gateway and desktop side.
  https://github.com/NousResearch/hermes-agent/commit/ab68c5ef
- **A merged observability integration was caught, reverted, and is being reapplied with a real fix — a good process signal, not a shipped regression.** `feat(observability): integrate NeMo Relay runtime and shared metrics` (opt-in, off-by-default telemetry) merged at 02:04 UTC and was reverted 24 minutes later after it caused an Anthropic streaming regression: one captured `contextvars.Context` was being re-entered across overlapping/nested provider, Relay-collection, and stream-cleanup callbacks, which Python rejects. A follow-up PR (#73120, open, not yet merged) reapplies the feature with each streaming callback copying its own context, plus a deterministic regression test that reproduces the exact failure on the reverted merge commit.
  https://github.com/NousResearch/hermes-agent/pull/73053, https://github.com/NousResearch/hermes-agent/pull/73120
- **Voice mode: saying an exact stop phrase now ends hands-free voice chat instead of being sent to the agent.** Match is strict (whole utterance, case-insensitive, punctuation stripped) so phrases like "stop doing that and try X" still reach the agent normally. Configurable via `voice.stop_phrases` (default `['stop']`).
  https://github.com/NousResearch/hermes-agent/commit/fab4c888
- No new tagged release since **v0.19.0 "Quicksilver"** (Jul 20). Today's 90+ commits are mostly desktop UI polish (thin scrollbars, session-tab slot mapping, composer image-lightbox routing, brand icons on known-domain links, chromeless code blocks, tooltip cleanup) alongside the fixes above.
