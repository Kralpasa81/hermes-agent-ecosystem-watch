## Broader AI agent ecosystem
- **OpenAI released GPT-6.1 Terra for high-volume computer-use workflows.** The model is available in ChatGPT Work, Codex, and the API as `gpt-6.1-terra`. OpenAI positions it as a faster, lower-cost successor to GPT-5.6 Terra for visual reasoning, browser/desktop action, and coding; standard API pricing is $1/M input, $0.05/M cached input, and $5/M output tokens. ([Announcement](https://openai.com/index/introducing-gpt-6-1-terra/))
