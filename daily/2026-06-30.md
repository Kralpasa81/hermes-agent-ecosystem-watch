## Hermes / Hermes-adjacent

- **Main-branch compression/session resilience:** Hermes merged a cluster of fixes around compression lock leases, cooldown authority, transient DB blips, and resume-time backoff persistence. This is meaningful for long-running sessions because context compression should fail open, release locks cleanly, and avoid stale lease state after early exits. Sources: https://github.com/NousResearch/hermes-agent/commit/58d8e25e671ead6d3ae4f30d6fa2f193bab44059, https://github.com/NousResearch/hermes-agent/commit/7479f26b3ff8, https://github.com/NousResearch/hermes-agent/commit/f2ccb2859f20
- **Cron pre-run scripts get a safer default timeout:** The default pre-run script timeout was raised from 120 seconds to 1 hour, making scheduled jobs less likely to fail before realistic setup/bootstrap scripts complete. Source: https://github.com/NousResearch/hermes-agent/commit/643b0dc67849
- **Gateway routing self-healing:** Hermes added message-time repair for stale `sessions.json` routing, a practical always-on gateway reliability fix for deployments where session routing metadata can drift. Source: https://github.com/NousResearch/hermes-agent/commit/3a83b6bc5dc8
- **Context references and web extraction improvements:** `@` references now expand concurrently, and `web_extract` bounds stored full-text size while returning concrete `read_file` offsets. These are small but practical improvements for agent research loops and large-source handling. Sources: https://github.com/NousResearch/hermes-agent/commit/c1b9de73f566, https://github.com/NousResearch/hermes-agent/commit/c9269fbfb689
- **Gateway and Desktop operator polish:** Hermes added per-platform typing-indicator controls, `/usage` context breakdowns by category, friendlier built-in tool labels, installed-theme detection in Desktop theme pickers, and container-boot recovery for gateways stranded in `degraded` or `draining` state. Sources: https://github.com/NousResearch/hermes-agent/commit/05ac16778bda, https://github.com/NousResearch/hermes-agent/commit/6aefc9d92595, https://github.com/NousResearch/hermes-agent/commit/481caa66f23c, https://github.com/NousResearch/hermes-agent/commit/04639adace67, https://github.com/NousResearch/hermes-agent/commit/463b1dfa9cbc, https://github.com/NousResearch/hermes-agent/commit/d3f2931b8cf9
