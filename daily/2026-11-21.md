# 2026-11-21

## Hermes / Hermes-adjacent
- **Hermes Enterprise — Nous Research × Microsoft partnership (announced Nov 18, at Microsoft Ignite Nov 17–20).** Hermes Agent is now available in native Microsoft enterprise services: **Hermes Desktop for Windows in the Microsoft Store**, **Microsoft Teams** (employees assign knowledge work — financial analysis, document drafts, inbox triage — and review the finished result in the same conversation), and **Azure Container Apps Sandboxes** (isolated microVMs that start in under a second and release compute when idle). **Collective Wisdom** turns a successful recurring approach into a reusable skill teammates can publish and share after review, with that shared intelligence kept as a private company asset rather than vendor training data. Organizations with strict data-residency/security/procurement rules can run it in their own Azure tenant. Nous notes Hermes is the **#1 public open agent on OpenRouter (~2 trillion tokens/day)**. This landed during Ignite and slipped past the 11-18→11-20 notes; recorded here retroactively. ([press release](https://nousresearch.com/hermes-enterprise-in-microsoft-teams), [X](https://x.com/NousResearch/status/2123535954946257096))
- **Hermes Plugin Hackathon top-10 winners published (Nov 20).** Nearly 1,000 entries; agents scored every submission and five community judges ranked the finalists. 1st **Foreman** (@PedValme), 2nd **Housemate**, 3rd **Plan Mode**, 4th **Seedguard**, 5th **Ariadne**, 6th **Mandate**, 7th **safe-swap**, 8th **Promise Keeper**, 9th **Hermes Canvas**, 10th **Hermes Gadget SDK**. The Marketplace now lists ~2,514 plugins. ([announcement](https://x.com/NousResearch/status/2123882430620733742), [marketplace](https://hermes-agent.nousresearch.com/marketplace))
