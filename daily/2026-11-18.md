## Broader AI agent ecosystem
- **OpenAI released GPT-6.2 Astra and GPT-6.2 Sol (Nov 17)** — its most capable models for cybersecurity tasks, and GPT-6.2 Astra is OpenAI's first externally released model to meet the **High threshold for AI Self-Improvement**. Available in ChatGPT Work and Codex for Plus/Pro/Enterprise/Edu, and generally available in GitHub Copilot (Pro+, Max, Business, Enterprise) for agentic coding and code review, where early testing shows more real issues caught with fewer tokens. ([announcement](https://openai.com/index/introducing-gpt-6-2-astra-sol/), [system card](https://deploymentsafety.openai.com/gpt-6-2-astra-sol), [Copilot](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available))
- **GitHub Copilot Fusion joined the public Terminal-Bench 4.1 leaderboard (Nov 17)** — Fusion Max posted a **71.2%** resolution rate, 5.4 points ahead of Opus 5.5 and Fable 5.2, while costing **88% less than Fable 5.2** and 57% less than Opus 5.5. Fusion also expanded to github.com, Visual Studio, and GitHub Mobile beta, and added models: Claude Sonnet 5.5 → Fusion Max, GPT-6.1 Terra → Fusion High, MAI-Code-2 → Fusion Standard. ([changelog](https://github.blog/changelog/2026-11-17-github-copilot-fusion-updates-more-availability-benchmarks-and-models))
- **Microsoft Ignite batch of Copilot releases (Nov 17):** Copilot code review gained adaptive effort and secret detection; **Copilot Evals** entered public preview; the Copilot CLI added Microsoft Entra sign-in (preview); and Copilot activity can now be monitored through Microsoft Agent 365. ([code review](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more), [Evals](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview), [Entra](https://github.blog/changelog/2026-11-17-github-copilot-cli-adds-microsoft-entra-sign-in-as-a-preview))
- **Anthropic launched Linked billing (beta, Nov 17)** — your app's customers can now pay for the Claude usage in your app through their own Claude organization; set `billing_policy` per request to choose who pays, and customers can set a spend cap or unlink your app. ([docs](https://platform.claude.com/docs/en/manage-claude/oauth-apps/organization-billing-connections))
