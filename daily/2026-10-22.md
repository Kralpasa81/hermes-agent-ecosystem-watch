# 2026-10-22

## Hermes / Hermes-adjacent

- [Hermes Agent v0.22.4](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.4) shipped on October 21. The patch removes unsolicited Desktop suggestion pills, avoids empty dependency-consent prompts for plugins that install nothing, and fixes WhatsApp re-pairing after logout. It also adds catalog entries for `mcp-serve` (running Hermes as an MCP server), `agent-importers` with Cursor support, and Linux sandbox/runtime options.

## Broader AI agent ecosystem

- GitHub made its [Copilot model-policy REST API](https://github.blog/changelog/2026-10-19-copilot-model-policy-api-for-enterprise-orgs-and-teams) generally available. Enterprise, organization, team, and agent-app policies can now be read and updated programmatically—important governance plumbing for multi-model coding-agent deployments.
