# 2026-09-01

## Hermes / Hermes-adjacent

- **Hermes Agent v0.21.0 "The Pantheon Release" — shipped Aug 31, 2026** ⭐  
  The largest Hermes release since v0.20.0. ~5,800 commits, ~2,475 merged PRs, 760+ contributors since v0.20.0.  
  Key highlights:
  - **Bot Mode** — built into the desktop app by default. Named agents with deterministic avatar faces, Discord-style group chats, @-mentions. Multi-agent finally looks like a product, not plumbing.
  - **`hermes peer`** — bot-to-bot DMs across profiles and gateways, from CLI or inside a conversation. Replies are durable and inspectable.
  - **Cron jobs that remember** — `continuity=true` carries each run's output into the next; cron agents now load/update persistent memory. Monitor-mode jobs skip the LLM entirely when nothing changed. Cron output can land in a bot's Bot Chat.
  - **Live subagent steering** — `delegate_task` gained mid-flight course corrections, early stop with partial results, JSON-schema output validation, per-delegation cost surfacing. Raised defaults: 250 iterations, 10 concurrent children.
  - **MCP command center** — MCP servers + catalog merged into one desktop page with drag-in import, background health checks, fleet cost/usage overlay, `hermes://` deep links for one-click server install.
  - **Browser agent** — the in-app browser is now driveable: Hermes navigates, clicks, and reads it directly. Pop-out to system browser with full link context menus.
  - **CLI power wave** — Ctrl+P fuzzy command palette, `/model` picker with live filter, `/status` shows reasoning mode/approvals/context, live cache-hit %/latency/tokens-sec in status bar, global emergency stop, session pin/unpin, terminal pets.
  - **Six new providers** — Meta Model API (Muse Spark), CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router, Actual Computer. New models: GLM-5.3-Flash, qwen3.8-max/flash, Gemini 3.7 Flash, MiniMax M3 free, Nemotron 3.5 Lightning. `model_overrides` lets you patch any model's context window or pricing without waiting on a release.
  - Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.8.31

## Broader AI agent ecosystem

- **GitHub Copilot in Visual Studio — August 2026 update (Aug 28)**  
  Organization-level custom agents: org/enterprise owners can now publish custom agents across all repos. Adjustable model thinking effort (Low/Medium/High). Improved model picker with pinning, collapsing, and management view showing context window sizes and costs. Git agent can review uncommitted changes and commits inline before PRs.  
  Source: https://github.blog/changelog/2026-08-28-github-copilot-in-visual-studio-august-update-2/

- **MCP specification 2026-07-28 — now fully ecosystem-adopted**  
  The stateless MCP spec (no handshake/sessions) has been fully absorbed by Cloudflare, Google, and major SDK maintainers (TypeScript, Python, Go, C#). HTTP-native, routable, cacheable, traceable. Hermes's MCP command center in v0.21.0 is built against this spec.  
  Source: https://blog.modelcontextprotocol.io/posts/2026-07-28/

## New / notable tools and platforms

- **Hermes Desktop (v0.21.0)** — Bot Mode marks the shift from terminal agent to a multi-agent desktop product. Native macOS/Windows/Linux.
- **`hermes://` deep links** — install any MCP server with one click and explicit confirmation. Meaningful infrastructure for the growing MCP server catalog.
- **Ramp Router / Actual Computer (new Hermes providers)** — two newly notable provider entries in the Hermes catalog, worth watching for routing optimization and computer-use workflows.
