# 2026-06-27

## Hermes / Hermes-adjacent

- **Hermes Agent latest tagged release remains `v0.17.0` / `v2026.6.19` (“The Reach Release”).** No newer tagged release was found today; the meaningful Hermes signal is focused post-release maintenance on main. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Photon / iMessage support continued to stabilize.** Main upgraded the `spectrum-ts` sidecar through `v7.0.0` and `v8.0.0`, and added tapback correlation to bot message context. This matters because Photon is one of the headline `v0.17.0` gateway surfaces and needs reliable reaction/message-context behavior for daily messaging use. Sources: https://github.com/NousResearch/hermes-agent/commit/5636c22828b0be1eadaf8968c7033efb27f705fa, https://github.com/NousResearch/hermes-agent/commit/4345b3e767c73405e143b2f03a1e4e7773c2b472, https://github.com/NousResearch/hermes-agent/commit/882730026739c51e6ae5c7cbe47e9b64a920a065
- **Self-hosted dashboard authentication got an OIDC compatibility fix.** Hermes now follows redirects during self-hosted OIDC discovery, which is important for real deployments behind identity-provider or reverse-proxy redirect flows. Source: https://github.com/NousResearch/hermes-agent/commit/fbf748b2824703f11a55bcf4b5ba7a5909c00865
- **Model-picker UX improved for custom / uncurated models.** The picker now surfaces the current custom or uncurated model in picker rows, reducing confusion when a deployment uses models outside the curated catalog. Source: https://github.com/NousResearch/hermes-agent/commit/d712a7fd735fbd2296e62b112397539f45fd467b

## Broader AI agent ecosystem

- **Claude Code `2.1.195` is the latest release note found today.** High-signal fixes include exact hook matching for hyphenated identifiers such as `mcp__brave-search`, explicit install consent for external plugins enabled only by project `.claude/settings.json`, several background-agent persistence/recovery fixes, remote-session startup provisioning checklist improvements, and voice-dictation fixes across macOS, Linux, and languages written without spaces. Source: https://docs.anthropic.com/en/release-notes/claude-code
- **GitHub expanded Copilot Business / Enterprise model choice with MAI-Code-1-Flash GA.** GitHub says Microsoft AI’s low-latency coding model is now generally available for Copilot Business and Enterprise, billed at provider list pricing under usage-based billing and gated by an admin policy. Source: https://github.blog/changelog/2026-06-26-mai-code-1-flash-for-copilot-business-and-copilot-enterprise
- **GitHub Copilot reporting added total merged PRs by AI adoption phase.** Enterprise and organization reports now expose `total_pull_requests_merged` in `totals_by_ai_adoption_phase`, helping teams compare absolute delivery throughput by adoption cohort instead of only per-user averages. Source: https://github.blog/changelog/2026-06-26-track-total-merges-by-adoption-phase-in-enterprise-and-organization-reports
- **OpenAI Codex CLI `0.142.3` shipped as a maintenance-only patch.** The release notes explicitly say there are no user-facing changes since `0.142.2`, so it is worth recording but not promoting as a major workflow signal. Source: https://github.com/openai/codex/releases/tag/rust-v0.142.3
