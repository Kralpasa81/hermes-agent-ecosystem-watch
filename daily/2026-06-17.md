# 2026-06-17

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but June 17 main-branch work delivered several high-signal provider, MCP, CLI, gateway, and container-deployment fixes.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Anthropic OAuth + MCP tool-name normalization was tightened.** Hermes now promotes leading `mcp_` tool names to `mcp__` on the Anthropic OAuth wire and maps them back after response normalization. The commit notes this prevents real MCP-server tools such as `mcp_<server>_<tool>` from being pushed into Anthropic's extra-usage billing lane. Source: https://github.com/NousResearch/hermes-agent/commit/b70a4e7533dce506a41f847b3fc082d6b6fe4a9b
- **Interactive CLI typing responsiveness improved.** Completion work is now wrapped so file/path completion does not block the prompt render loop on every keystroke, and URL tokens no longer trigger filesystem path completion. This is especially relevant for WSL2 and slow-filesystem setups. Sources: https://github.com/NousResearch/hermes-agent/commit/f48b3120375d81733ed15fd16e2a606f19081923, https://github.com/NousResearch/hermes-agent/commit/fbaad3031abe74a14dc02569eb73d003f23120bb
- **Container deployment detection was broadened for Kubernetes/containerd/CRI-style environments.** `is_container()` now recognizes Kubernetes environment markers and cgroup/mountinfo patterns used by containerd and CRI-O, reducing false negatives that can affect profile home resolution, gateway behavior, config, and doctor checks. Source: https://github.com/NousResearch/hermes-agent/commit/5e01a5dbf1b7bc0144d9057be706da1ea9f065c3
- **Gateway message timestamps are now opt-in rather than unconditional.** Hermes still captures and persists timestamp metadata, but in-context timestamp rendering is gated behind `gateway.message_timestamps.enabled` with a default of `false`. Source: https://github.com/NousResearch/hermes-agent/commit/36ae958473b8530ffb1a395c4944b8cdbcae82fe

Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.179

Source: https://developers.openai.com/codex/changelog
