# 2026-06-06

## Hermes / Hermes-adjacent

- **Hermes Agent v0.16.0 / `v2026.6.5` shipped as “The Surface Release.”** This is the day’s strongest signal: Hermes now has a first-class native desktop app for macOS, Linux, and Windows; remote gateway sign-in via OAuth or username/password; concurrent multi-profile desktop sessions; drag-and-drop / clipboard-image chat UX; in-app self-update; a much larger browser dashboard admin panel; Quick Setup through Nous Portal; fuzzy model picking across surfaces; `/undo`; a leaner default skill set; NVIDIA/skills as a trusted Skills Hub tap; and security hardening including a Starlette CVE pin, SSRF off-loop work, and subprocess credential stripping. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **The official Hermes docs/front page now reinforce the “desktop + portal setup” path.** The docs point Windows/macOS users to the Hermes Desktop installer and identify `hermes setup --portal` as the fastest setup path through Nous Portal for model, web search, image generation, text-to-speech, and browser access. Source: https://hermes-agent.nousresearch.com/docs
- **Post-release main-branch activity continued around usability and workflow correctness.** Notable follow-up commits added usage-aware credits with in-session notices and a `/usage` view, displayed custom profile alias names in profile list/show, warned when a desktop main-model switch leaves auxiliary tasks pinned to another provider, improved delegate handling for content-block tool results, and treated ntfy topic targets as explicit. Sources: https://github.com/NousResearch/hermes-agent/commit/fcb1944, https://github.com/NousResearch/hermes-agent/commit/5af899c, https://github.com/NousResearch/hermes-agent/commit/b91aade, https://github.com/NousResearch/hermes-agent/commit/f83918c, https://github.com/NousResearch/hermes-agent/commit/338c074

## Broader AI agent ecosystem

- **Claude Code’s latest changelog shows reliability and governance hardening around real agent workflows.** Recent entries include a `fallbackModel` setting for up to three fallback models, cross-session messaging hardening so relayed messages do not carry user authority, version-range managed settings, improved MCP/session environment handling, and many terminal / remote-session reliability fixes. Source: https://docs.anthropic.com/en/release-notes/claude-code
- **The MCP 2026-07-28 release candidate is a major interoperability signal and includes breaking changes.** The MCP blog describes it as the largest protocol revision since launch, adding a stateless core for ordinary HTTP infrastructure, extensions such as MCP Apps for server-rendered UI and Tasks for long-running work, authorization alignment with OAuth / OpenID Connect deployments, JSON Schema 2020-12 support, and a formal deprecation policy. Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **OpenAI continues to frame Codex as a broader productivity surface, not only a coding tool.** OpenAI’s June 2 report post says Codex has more than 5 million weekly active users, that knowledge workers now represent about 20% of users, and that common non-developer uses include reports, spreadsheets, presentations, contracts, research, data analysis, workflow automation, and lightweight tools. Source: https://openai.com/index/codex-for-knowledge-work
