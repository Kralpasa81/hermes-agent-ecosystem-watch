# 2026-11-17

## Hermes / Hermes-adjacent
- **Hermes Agent v0.23.2 released** (tagged Nov 16, 20:59 UTC) — the latest stable patch rolls up ~1,989 merged PRs (7,918 non-merge commits, 5,211 changed files) since v0.23.1 into the GitHub release, Microsoft Store app, Docker, and Hermes Cloud. Full curated notes ship with v0.24.0, but the tag calls out several window changes directly relevant to running Hermes in production: **durable subagents** that survive a gateway restart or crash and continue on their own conversation; `hermes fallback check` for fallback-chain readiness; `hermes update --force` to stop gateways at once instead of draining; **per-job cron options** (`wrap_response`, a fresh thread per run); one prompt-cache clock per session; new plugin APIs (`ctx.fork_session`, `ctx.redact_text()`, `ctx.register_idle_task`); one-time `browser_vault` codes from Telegram/Discord; opt-in shared Telegram DM threads; Gemini Interactions API by default (Gemini 3+ and Gemini 4 Carbon) plus fast mode for Claude Mythos 5.2; and compatibility shims with a slimmer macOS bundle. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.2))
