## Broader AI agent ecosystem

- **Claude Code `2.1.193` is the latest release note found today.** High-signal changes include `autoMode.classifyAllShell`, auto-mode denial reasons in transcripts/toasts/recent denials, live bash-mode path autocomplete, startup notices when MCP servers need authentication, automatic memory-pressure reaping for idle background shell commands, and a new `claude_code.assistant_response` OpenTelemetry event that may require explicit opt-out in prompt-logging deployments. Source: https://docs.anthropic.com/en/release-notes/claude-code
- **OpenAI Codex Remote reached general availability on June 25.** The changelog says users can start or continue work on a connected Mac or Windows host from the ChatGPT mobile app, with authenticated one-to-one QR pairing; it also notes a new DigitalOcean plugin for provisioning a Droplet and connecting it as a remote workspace. Source: https://developers.openai.com/codex/changelog
- **GitHub Copilot code review gained analysis-depth / efficiency updates, and enterprise-managed plugin controls expanded.** Copilot code review now uses built-in file-exploration tools from Copilot CLI / SDK for cost efficiency, while `strictKnownMarketplaces` lets enterprises control plugin installation in VS Code and GitHub Copilot CLI. Sources: https://github.blog/changelog/2026-06-25-copilot-code-review-analysis-depth-and-efficiency-updates, https://github.blog/changelog/2026-06-25-enterprise-managed-settings-now-support-strictknownmarketplaces-in-vs-code-and-the-cli
- **Anthropic introduced Claude Tag on June 23.** It is a beta Team / Enterprise Slack surface where teams can tag `@Claude`, grant selected channel/tool/codebase access, and delegate asynchronous work; Anthropic explicitly frames it as an evolution of Claude Code toward proactive team workflows. Source: https://www.anthropic.com/news/introducing-claude-tag
