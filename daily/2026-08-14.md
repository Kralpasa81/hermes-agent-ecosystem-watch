### Recent major Hermes release: v0.20.0 (2026.08.03) - The Herald Release
✧️ **Highlight:** Transformative voice features - streaming conversational voice with barge-in (interrupt mid-sentence), on-device wake words, and hands-free control across CLI, desktop, and gateway platforms
✧️ **Highlight:** Outbound webhooks - Hermes pushes signed lifecycle events to your HTTP endpoints for programmatic integration
✧️ **Highlight:** Grounded citations skill - Research with verifiable sources and fact-checking capabilities
✧️ **Highlight:** Agent-to-Agent (A2A) v1.0 - Hermes can now discover, talk to, and be driven by other A2A-compatible agents
✧️ **Highlight:** Desktop app becomes a platform - Artifacts with live preview, plugin SDK, quick-entry from anywhere
✧️ **Highlight:** CLI power-user features - `!` shell mode, `/init`, `/diff`, `/context`, `/focus` commands, and `hermes import-agent` migration tool

Massive release with ~3,650 commits, ~1,400 merged PRs, and ~1,200 issues closed.
