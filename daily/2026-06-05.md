## Broader AI agent ecosystem

- **GitHub Copilot added an Agent tasks REST API in public preview for Copilot Pro, Pro+, and Max.** Users can programmatically start and track Copilot cloud-agent tasks, enabling custom automations such as multi-repo refactors, developer-portal repository setup, and recurring release prep. Source: https://github.blog/changelog/2026-06-04-agent-tasks-rest-api-now-available-for-copilot-pro-pro-and-max
- **GitHub Copilot introduced larger context windows and configurable reasoning levels.** GitHub says supported models can now use one-million-token context windows and adjustable reasoning levels in VS Code, Copilot CLI, and the GitHub Copilot app, with higher settings consuming more AI credits. Source: https://github.blog/changelog/2026-06-04-larger-context-windows-and-configurable-reasoning-levels-for-github-copilot
- **Copilot code review is becoming more MCP- and skills-aware.** GitHub's June 2 public preview adds custom agent skills, MCP server connections, and a deeper Medium analysis tier so code review can use organization-specific context and higher-reasoning review paths when needed. Source: https://github.blog/changelog/2026-06-02-shape-copilot-code-review-around-your-team
- **MCP security scrutiny is increasing.** An active individual IETF Internet-Draft, not formally endorsed by the IETF, catalogs MCP implementation risks including SSRF, excessive permissions, prompt-injection exposure, lifecycle bypass, information leakage, authentication gaps, and protocol pivoting. Source: https://datatracker.ietf.org/doc/draft-mohiuddin-mcp-security-considerations
