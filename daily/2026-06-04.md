- **Hermes Agent main branch stayed highly active, with dashboard auth and remote-gateway access improvements leading the day.** A new bundled `dashboard_auth/basic` username/password provider adds a no-OAuth option for self-hosted dashboards, while related work adds non-redirect password login, self-hosted OAuth client registration via `hermes dashboard register`, OAuth-aware remote gateway connection handling, and clearer refused-WebSocket diagnostics. Sources: https://github.com/NousResearch/hermes-agent/commit/9cbc37e, https://github.com/NousResearch/hermes-agent/commit/3c163cb, https://github.com/NousResearch/hermes-agent/commit/40420a619b588049f138889add2417cb9dcb7b91

Sources: https://github.com/NousResearch/hermes-agent/commit/2e628ae, https://github.com/NousResearch/hermes-agent/commit/03ba06e, https://github.com/NousResearch/hermes-agent/commit/7402706, https://github.com/NousResearch/hermes-agent/commit/30c7b78, https://github.com/NousResearch/hermes-agent/commit/40fbb0f
