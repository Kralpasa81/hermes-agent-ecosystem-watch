## Broader AI agent ecosystem
- **Anthropic launches Claude Ship (announced Nov 23, captured today).** A post-PR automation layer: **Code Review** (now GA) performs adversarial, categorized PR review at Quick/Standard/Deep levels; **PR Steward** (beta) keeps a PR green across failing CI, merge conflicts, and review feedback, commenting what it changed and accepting `@claude` / `@claude stop`; **Claude Approvals** (beta) applies a repo policy file to decide what is mergeable ("a smarter CODEOWNERS"). A new `/ship` command in Claude Code pushes, opens, reviews, and iterates on a PR. Claude Team + Enterprise, GitHub repos. ([article](https://claude.com/resources/articles/introducing-claude-ship), [Reuters](https://www.reuters.com/business/anthropic-launches-claude-ship-help-developers-ship-code-faster-2026-11-23/))
- **Skills over MCP enters public beta; Tasks and Elicitation hit GA (announced Nov 24, captured today).** MCP servers can now ship **skills** alongside tools (loaded only when needed, updated with the server); **Tasks** lets a server run long-running work or full agent loops in the background while Claude keeps working; **Elicitation** lets a server pause mid-call to ask the user for input (e.g. confirm cost before a paid or destructive action). **File Uploads** (pass PDFs/spreadsheets/images to a server without the context window) is rolling out soon. These are open MCP spec extensions, so any compatible client — not just Claude — can use them; MCP now sees 700M+ monthly SDK downloads and 10k+ connectors. ([article](https://claude.com/resources/articles/skills-over-mcp-tasks-and-more))
- **Claude "Install as app" (announced Nov 24, captured today).** Artifacts can be installed as native Mac/Windows desktop apps (own icon and window, notifications, menu-bar/tray presence) with three permission levels, sharing, and automatic updates when the underlying artifact changes. Beta, all plans. ([article](https://claude.com/resources/articles/install-as-app))

## New / notable tools and platforms
- **Claude Ship** — Anthropic's new PR review/fix/approve product (Code Review GA + PR Steward + Claude Approvals). A distinct platform from Claude Code and the clearest move yet toward policy-driven, AI-owned merge gates in the coding-agent category.
- **MCP Skills / Tasks / Elicitation / File Uploads** — new open MCP spec extensions that make servers behave more like agents (shipping knowledge, running background work, asking for input, receiving files).

## Starred signals today

- ⭐ **Claude Ship** — Anthropic productizes PR review, fix, and approval into one automation layer with a policy-driven approval agent.
