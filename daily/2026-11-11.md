# 2026-11-11

## Hermes / Hermes-adjacent
- **Hermes Cloud is live (announced Nov 9).** Nous now hosts Hermes Agent in its own cloud: pick a name and a model in Nous Portal and the agent runs 24/7 in its own container, opening in a browser tab with the same interface as Hermes Desktop. Because it stays up while your laptop is closed, it can run scheduled jobs and answer on any channel. Chats, Group Chats, plugins and settings in the Webapp match a self-hosted install, and Hermes Desktop can attach to a Cloud agent to continue the same chats. Plus, Super, and Ultra Portal plans each include one Cloud agent out of the box. A meaningful limits/access shift — Hermes gains a first-party, always-on managed-hosting path. ([announcement](https://x.com/NousResearch/status/2119851439904510217))
- **Claude Fable 5.2 is available in Hermes Agent (Nov 9).** Nous highlighted trying Anthropic's new Fable 5.2 model inside Hermes the same day Anthropic shipped it. ([post](https://x.com/NousResearch/status/2119927476784607697))
- **Hermes Plugin Hackathon submissions close today (Nov 11, 5 PM EST).** Nous reports "hundreds" of submissions received with judging to follow; accepted entries are listed in the Hermes Marketplace. ([post](https://x.com/NousResearch/status/2120271539006222576))
- **Nous Portal "Sign in with ChatGPT" now supports ChatGPT Business plans (Nov 10).** A small sign-in/access broadening for Portal. ([post](https://x.com/NousResearch/status/2120215605123178671))

## Broader AI agent ecosystem

Shipped ahead of Anthropic's IPO, reportedly slated for Nov 19–20.
