# 2026-10-02

## Hermes / Hermes-adjacent

*   **Hermes Agent v0.21.5 (2026-09-24) Released:** The latest stable release of Hermes Agent. ([Source](https://github.com/NousResearch/hermes-agent/releases/tag/v2026.9.24))
*   **Key Features from Hermes Agent v0.21.0 (2026-08-31) Review:**
    *   **Bot Mode:** Agents can now form a "society" within the desktop app, with named bots, avatars, and shared group chats, transforming multi-agent interaction into a seamless collaborative experience.
    *   **`hermes peer` for Bot-to-Bot DMs:** Enables direct and durable messaging between any Hermes agent, across profiles and gateways, allowing complex inter-agent workflows.
    *   **Persistent Cron Jobs:** Scheduled tasks now retain and update memory across runs, with `continuity=true` to carry output, dedicated notepads, and intelligent LLM-skipping when no changes are detected.
    *   **Live Subagent Orchestration:** The `delegate_task` function now supports real-time management of child agents, including listing, steering mid-flight, early termination with partial results, JSON-schema validation, and per-delegation cost surfacing.
    *   **Enhanced MCP Command Center:** A unified desktop page for MCP servers and the tool catalog, featuring drag-in import, background health checks, cost/usage overlays, and `hermes://` deep links for server installation.
    *   **CLI Power Wave:** New features include a fuzzy command palette (`Ctrl+P`), a filtered `/model` picker, an informative `/status` command, global emergency stop, session pin/unpin, and rotating task-oriented composer placeholders.
    *   **Agent-Driven Desktop Browser:** Hermes agents can now directly navigate, click, and read the in-app browser, extending their capabilities to interact with web content.
    *   **Expanded Provider & Model Catalog:** Integration of six new providers (Meta Model API (Muse Spark), CommandCode, Tencent TokenPlan, Nebius Token Factory, Ramp Router, Actual Computer) and new models (GLM-5.3-Flash, qwen3.8-max/flash, Gemini 3.7 Flash, MiniMax M3 free, Nemotron 3.5 Lightning). `model_overrides` config allows custom patching of model metadata.
    *   **Comprehensive Security Hardening:** Enhanced security with mandatory write approval for agent-instruction files, extensive redaction of secret leaks, Windows destructive command approval, and a stable TCC signing identity for macOS permissions.
