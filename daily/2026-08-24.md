# 2026-08-24

## Hermes / Hermes-adjacent
- **New Release**: Nous Research released Hermes Agent v0.15.2 (2026.8.23.2) with significant improvements to session persistence reliability and TUI performance optimization.
- **Gateway Update**: Fixed a bug where TUI frontend exit would never commit sessions to OpenViking for users with `session_persistence: none` [#86742](https://github.com/NousResearch/hermes-agent/issues/86742)
- **Desktop App Improvement**: Addressed the issue where update banners showed stale 'commits behind' after successful updates [#38618](https://github.com/NousResearch/hermes-agent/issues/38618)

## Broader AI agent ecosystem
- **MCP Security Alert**: CSA Research published a bulletin about MCP auto-execution risks with coding assistants, emphasizing the need for immediate patching of vulnerable extensions [#1670](https://labs.cloudsecurityalliance.org/research/csa-research-note-mcp-ai-coding-assistant-credential-theft-2/)
- **New Open Source Tool**: Project LiberOS released an early version of their 'MCP-agnostic plugin adapter' that allows running existing plugins across multiple MCP-compatible servers

## New / notable tools and platforms
