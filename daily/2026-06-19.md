# 2026-06-19

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but June 19 main-branch activity was high-signal for hosted relay, bundled skills, tool capability, dashboard reliability, and install hardening.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Hosted relay moved from merged plumbing to verified end-to-end operation.** A relay trigger bug was fixed so NAS-hosted agents self-provision from relay config rather than the unrelated package-manager `is_managed()` state, and a follow-up relay fix reports live staging verification of a Discord mention round-trip through shared connector bot → tenant routing → authenticated agent WebSocket → Discord reply. Sources: https://github.com/NousResearch/hermes-agent/pull/48724, https://github.com/NousResearch/hermes-agent/pull/48828
- **A new bundled `html-artifact` skill consolidates visual/explanatory artifact work.** It folds `sketch`, `architecture-diagram`, and `concept-diagrams` into one dependency-free bundled skill for self-contained HTML artifacts such as explainers, implementation plans, incident/status reports, SVG diagrams, design comparisons, and small interactive editors. Source: https://github.com/NousResearch/hermes-agent/pull/48899
- **`image_generate` gained image-to-image / editing support across providers.** The unified tool now accepts source/reference images, exposes dynamic capability-aware schema, and returns clear unsupported-modality errors instead of silently dropping edit inputs. Sources mention FAL edit endpoints, OpenAI `images.edit`, xAI image edits, and Krea reference-guided generation. Source: https://github.com/NousResearch/hermes-agent/pull/48705
- **Model and provider UX improved.** The Desktop model picker now has a `Refresh Models` control that busts stale provider-model cache state so live-only models can reappear after failed cache refreshes. Structured provider errors are also summarized more clearly. Source: https://github.com/NousResearch/hermes-agent/pull/48691
- **Dashboard and hosted chat reliability continued to harden.** Dashboard chat TUI argv resolution now runs off the event loop to avoid reverse-proxy WebSocket drops during slow build resolution; hosted dashboard chat stays alive or restarts cleanly on exit/idle-exit hotkeys; large dashboard uploads clean up temp files even on client disconnects; Slack setup now includes allowed-user validation and wildcard handling; WebUI Docker installs work from read-only source trees. Sources: https://github.com/NousResearch/hermes-agent/pull/48561, https://github.com/NousResearch/hermes-agent/pull/48259, https://github.com/NousResearch/hermes-agent/pull/48880, https://github.com/NousResearch/hermes-agent/pull/48541
- **CLI/session safety received practical fixes.** Hermes worktrees are locked so concurrent processes cannot clobber them, gateway lifecycle commands are blocked from inside the gateway process, session-store failures now surface visible warnings, and SQLite FTS fallback behavior was fixed for environments without trigram tokenizers. Source: https://github.com/NousResearch/hermes-agent/commits/main

## Broader AI agent ecosystem

- **Claude Code `v2.1.183` shipped with stronger auto-mode safety and reliability fixes.** It blocks destructive git and infrastructure-destroy commands unless explicitly requested, blocks `git commit --amend` unless the current-session agent created the commit, adds model deprecation/auto-update warnings, adds `attribution.sessionUrl`, improves `/config --help`, and fixes issues around subagents, WebSearch, Windows Terminal rendering, thinking-only turns, MCP auth-stub tools in headless/SDK mode, tmux teammate panes, background tasks, and scheduled/webhook trigger classification. Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.183
- **OpenAI Codex app 26.616 added Record & Replay for macOS.** The Codex changelog describes it as a way to turn a demonstrated workflow into a reusable skill; initial availability excludes EEA, UK, and Switzerland and requires Computer Use. The same app update also adds bulk automation-history actions and Browser Use routing/annotation improvements. Source: https://developers.openai.com/codex/changelog
- **GitHub Copilot code review now uses repository-level `AGENTS.md`.** Copilot code review can automatically use a root `AGENTS.md` to shape review feedback, and GitHub also improved review-request UI for draft PRs and collapsed some Copilot review timeline noise. Source: https://github.blog/changelog/2026-06-18-copilot-code-review-agents-md-support-and-ui-improvements
- **GitHub expanded model availability and announced one Copilot model deprecation.** MAI-Code-1-Flash is rolling out to more Copilot surfaces, while Opus 4.6 (fast) is scheduled for deprecation across Copilot experiences on June 29, 2026 with Opus 4.8 (fast) as the suggested alternative. Sources: https://github.blog/changelog/2026-06-18-mai-code-1-flash-available-on-more-copilot-surfaces, https://github.blog/changelog/2026-06-18-upcoming-deprecation-of-opus-4-6-fast
