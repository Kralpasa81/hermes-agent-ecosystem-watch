# 2026-07-23

## Hermes / Hermes-adjacent

- **Clarify-request lifecycle unified and hardened across every surface.** Six related PRs landed as one sweep: `fix(clarify): one canonical timeout across CLI, TUI/desktop, and gateway` (#69774, fixes #36531 — CLI previously read a non-existent config key and silently fell back to a hardcoded 120s instead of the real `agent.clarify_timeout`); `fix(gateway): deliver assistant prose before the clarify poll` (#69775 — the clarify question used to render above its own explanation because the poll won a race against buffered streamed prose); `fix(tui_gateway): tolerate late clarify + terminal.read replies after timeout` (#69773 — a slow renderer or reconnect that dropped `tool.complete` used to hit a raw JSON-RPC error instead of the same graceful late-reply handling secret/sudo prompts already had); `fix(desktop): keep clarify answerable across reconnect/hydration + tool-progress off` (#69795); and two rendering/UX fixes (#69796, #69869) for choice text wrapping, garbage-payload validation, and keyboard focus. Together these close a real class of "the agent asked a question and the app either mishandled the answer or broke the timeout" bugs on every Hermes surface.
  https://github.com/NousResearch/hermes-agent/commit/507d479c8c
- **Desktop multi-profile session-identity bugs fixed.** `fix(desktop): end the #67603 model-switch dup, cross-profile session bleed, and [System:] bubble` (#69861) closes a bug where a model-switch notice — stored as a `role=user` `[System: …]` row so strict OpenAI-compatible providers don't reject a leading non-user message — was rendered as a duplicate visible bubble and could leak between profiles after a reconnect. Paired with `fix(desktop): scope the remembered session id per profile` and `fix(desktop): route tiled session resumes to the owning profile` (#69887), which stop a relaunch under Profile B from restoring a session that actually belongs to Profile A. Direct correctness fix for anyone running multiple Hermes desktop profiles.
  https://github.com/NousResearch/hermes-agent/commit/e59dcf46f1
- **Slack adapter reliability hardening (C16/C10/C7 cluster).** A batch of fixes bounds every previously-unbounded in-memory cache in the Slack adapter (DM-resolution cache, thread-context cache, user-name cache, approval/clarify tracking) with oldest-first eviction, closing a failure mode where a busy long-running Slack bot could either grow memory without bound or silently go quiet on its most active thread. Alongside: `fix(gateway): make post-stream media delivery explicit-only` stops the gateway from re-uploading stale local file paths as images after an otherwise clean reply, and `fix(slack): resolve bare user targets to DMs across all adapter send paths` fixes DM delivery for image/video/document/clarify sends, not just plain replies.
  https://github.com/NousResearch/hermes-agent/commit/533e541237
- **Desktop hands-free voice now speaks the whole turn.** `fix(voice): speak the whole turn, not just its first bubble; idle-flush held narration` fixes a bug where a tool-calling turn bound live speech to the first assistant bubble only — every later interim update and the final answer were silently dropped from narration. Also fixes narration lines with no trailing punctuation getting stuck in the sentence chunker until end-of-turn.
  https://github.com/NousResearch/hermes-agent/commit/9859e1f7df
- Smaller items merged today, none release-critical: computer-use perf pass (capped screenshot capture size, cached vision routing, macOS cursor-overlay disabled by default for idle CPU, X11 active-window tie-break fix); native OS credit-usage alerts as toasts with a billing-page nudge; per-task model/provider override dropdown in the desktop Kanban board. No tagged release since v0.19.0 "Quicksilver" (Jul 20) — today's commits continue post-release stabilization.

## Broader AI agent ecosystem

- **Claude Code `2.1.218` (Jul 22)** closes a real security gap: agent frontmatter hooks now require the *agent file's own folder* to have accepted workspace trust before running, closing a path where hooks could execute from an untrusted folder. Also changes `/code-review` to run as a background subagent (keeps stacked slash commands as its target instead of filling the conversation), and fixes a fork-session-lineage loss after compaction in headless/SDK sessions.
  https://github.com/anthropics/claude-code/releases/tag/v2.1.218
- **OpenAI launched Presence (Jul 22)**, its first managed enterprise product for deploying and governing AI voice and chat agents in production — bundling policies, escalation rules, monitoring, and guardrails instead of leaving enterprises to build that orchestration themselves. Limited availability for eligible enterprise customers. Notable as a packaging/maturity signal for the broader "managed agent deployment" category that Hermes gateway users should track for competitive context.
  https://openai.com/index/introducing-openai-presence
