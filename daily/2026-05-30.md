## Broader AI agent ecosystem

- **Anthropic introduced Claude Opus 4.8 with a clear coding-agent angle.** Anthropic positions Opus 4.8 as stronger on coding, agentic tasks, and long-running work; the announcement also notes Claude Code "dynamic workflows" and a cheaper fast mode for Opus 4.8. Source: https://www.anthropic.com/news/claude-opus-4-8
- **Anthropic raised Claude Code usage limits.** The company says it doubled Claude Code's five-hour rate limits for Pro, Max, Team, and seat-based Enterprise plans, and removed the peak-hours reduction for Pro and Max accounts. Source: https://www.anthropic.com/news/higher-limits-spacex
- **GitHub moved the Copilot app into technical preview.** GitHub frames it as a GitHub-native desktop workflow for agentic development, with isolated sessions, integrated terminal/browser validation, and pull-request handoff from the same workspace. Source: https://github.blog/changelog/2026-05-14-github-copilot-app-is-now-available-in-technical-preview/
- **GitHub made secret scanning in the GitHub MCP Server generally available.** This brings pre-commit and pre-PR secret scanning into MCP-compatible coding agents and IDEs, which is relevant for practical agent safety and workflow automation. Source: https://github.blog/changelog/2026-05-05-secret-scanning-with-github-mcp-server-is-now-generally-available/
