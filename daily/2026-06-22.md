## Hermes / Hermes-adjacent

- **Hermes Agent latest tagged release remains `v0.17.0` / `v2026.6.19` (“The Reach Release”).** No newer tagged Hermes release was found today, so `v0.17.0` remains the baseline for channel, automation, subagent, memory, desktop, dashboard, and gateway tracking. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Hermes main added a meaningful computer-use follow-up wave.** The most notable changes were cross-platform `cua-driver` support for macOS / Windows / Linux, whole-screen / desktop capture targeting, desktop-visible macOS permission preflight, vision-capture fixes, and telemetry disabled by default unless users opt in. Sources: https://github.com/NousResearch/hermes-agent/commit/f2e37549c673ab3645e5784d066ee95193c119e2, https://github.com/NousResearch/hermes-agent/commit/30e5d0092dacc35fb0a09d537077e93f495bb90a, https://github.com/NousResearch/hermes-agent/commit/0223ea5f590aec3697ebad6b7f533b5e5df2cc83, https://github.com/NousResearch/hermes-agent/commit/f1e6d39a74faf4224f0d365009f31d0589c8b8eb
- **Hermes security and gateway hardening continued after the release.** Notable fixes include credential redaction in approval prompts, denial of root-level credential stores in media delivery, restricting dashboard plugin backend imports to bundled plugins, and profile-home resolution for file-tool `~` paths. Sources: https://github.com/NousResearch/hermes-agent/commit/c080b2dc3ee672251cce6de4d002632f4027f9f8, https://github.com/NousResearch/hermes-agent/commit/100e7be20ed88d8b78adb6664b41c8821052d592, https://github.com/NousResearch/hermes-agent/commit/8845f3316c26732cb758d7f7300b9dbf83ef2728, https://github.com/NousResearch/hermes-agent/commit/15880da8bbd5c9a48c3bc5f6955bea86fba54965
- **Goal and long-running-work support improved on main.** `/goal` gained evidence-based completion contracts, and `/goal wait <pid>` can park the loop on a background process, which is relevant to autonomous verification and long-running terminal workflows. Sources: https://github.com/NousResearch/hermes-agent/commit/2ba1cfeb2e28c77a3ae2323772e5a6bca43844cb, https://github.com/NousResearch/hermes-agent/commit/ff85af3fc7d38e663e08cdada10e26f3d99ab91e
- **A new optional `cloudflare-temporary-deploy` skill landed on main.** This is worth watching as a practical artifact / preview-deploy helper rather than as a broad platform shift. Source: https://github.com/NousResearch/hermes-agent/commit/ff08e60c63ada076aecc0c3243e2cfc9258db4f8

## Broader AI agent ecosystem

Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.186
- **OpenAI Codex CLI `0.142.0` became the latest stable release.** Strong signals include remote plugin organization and recommendations, configurable rollout token budgets across agent threads, app-server controls for multi-agent delegation, indexed web-search mode, scheduled UTC time reminders / current-time access, and reliability fixes for remote environments, stdio MCP sessions, plugin loading, and terminal subagent error reporting. Source: https://github.com/openai/codex/releases/tag/rust-v0.142.0
- **OpenAI published “Codex-maxxing for long-running work.”** This is not a product release, but it is a useful workflow signal: OpenAI is explicitly positioning Codex as a persistent workspace for long-running projects, verifiable steps, continuity across workstreams, and calibrated human oversight. Source: https://openai.com/index/codex-maxxing-long-running-work/
