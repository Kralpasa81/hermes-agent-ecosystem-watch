# 2026-11-10

## Hermes / Hermes-adjacent
- **Hermes Agent v0.23.1 released (patch; notes dated Nov 9, tagged Nov 10 01:42 UTC).** Rolls up ~618 merged PRs since v0.23.0 into a stable release. Headline fix: the live plugin catalog (`plugin-catalog.json`) had grown past the 2 MiB cap clients accept, so every `hermes plugins install` silently fell back to the catalog the release shipped with — plugins added since the last update couldn't be found, and installs pinned to the release's own catalog. v0.23.1 raises the cap to 16 MiB so the live catalog is used again; installs on ≤v0.23.0 keep falling back until updated. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.1), fix [#151860](https://github.com/NousResearch/hermes-agent/pull/151860))
- **A broader plugin API ships in the same window (undocumented here; full curated notes ship with v0.24.0).** Session-scoped environment values, plugin JSON-RPC methods and events, `llm.oneshot` auxiliary tasks, a compression-stable `conversation_id`, an `on_session_open` gateway hook, and a `post_curator_run` hook — plus Esc backtrack in the TUI/CLI, group chats on a gateway without Desktop, `hermes gateway attach`, and `hermes clipboard image --json`.
