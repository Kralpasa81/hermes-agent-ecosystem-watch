## Broader AI agent ecosystem

- **GitHub Copilot code review billing changes take effect today.** Starting June 1, 2026, Copilot code reviews on private repositories consume GitHub Actions minutes in addition to Copilot AI Credits; public repositories remain unchanged for Actions-minute billing. This matters for agentic review workflows that run at PR scale. Source: https://github.blog/changelog/2026-04-27-github-copilot-code-review-will-start-consuming-github-actions-minutes-on-june-1-2026
- **GitHub Copilot's AI Credits billing model also goes live today.** GitHub's preparation post says the new AI Credits unit goes live on June 1 and points admins/users to usage reports for estimating consumption by model and surface. Source: https://github.blog/changelog/2026-05-12-april-reports-are-now-available-to-prepare-for-usage-based-billing
