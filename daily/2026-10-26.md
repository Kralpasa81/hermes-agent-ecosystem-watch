# 2026-10-26

## Hermes / Hermes-adjacent
- **GitHub Copilot is leaving Hermes core for a Labs plugin.** A merged Hermes mainline change moves `copilot` and `copilot-acp` into the Nous-maintained `github-copilot` Labs plugin, while introducing generic provider-profile hooks in core. Profiles that already select Copilot are designed to auto-install the plugin; users relying only on `gh auth token` are prompted to run `hermes auth add copilot`. This narrows core scope, reduces accidental GitHub token use in non-Copilot profiles, and makes provider extensions more modular. ([Merged PR #144788](https://github.com/NousResearch/hermes-agent/pull/144788))

## Broader AI agent ecosystem
- **MCP reference servers v2.1.0 ships security fixes.** The release fixes eight vulnerabilities across the filesystem, everything, and fetch servers. Deployments should update `@modelcontextprotocol/server-filesystem` and `@modelcontextprotocol/server-everything` to `2.0.1`, plus `mcp-server-fetch` to `2026.10.24`. ([Release](https://github.com/modelcontextprotocol/servers/releases/tag/v2.1.0))

## New / notable tools and platforms
- No new platform was promoted today. The noteworthy movement is maintenance and interoperability: Hermes is separating a major provider integration into an installable Labs plugin, while MCP reference servers received a security update.
