## Broader AI agent ecosystem
- **OpenAI corrects Codex usage and merges ChatGPT + Codex limits (Nov 25).** OpenAI emailed Codex subscribers that some **GPT-6.2 Astra / Sol** requests were undercounted against their allowance (including Ultrafast mode) and has corrected the counting — so users may now hit their limit sooner, at the same price. Separately, as OpenAI folds ChatGPT's "chat" and "work" tabs into one interface, it will begin **sharing usage limits between ChatGPT and Codex** for Plus, Pro, and Business plans in December. ([The Verge](https://theverge.com/ai-artificial-intelligence/1042187/openai-is-combining-chatgpt-and-codex-usage-limits), [TechCity Authority](https://techcityauthority.com/2026/11/openai-codex-usage-correction-makes-limits-run-out-sooner.html))
- **Claude Code adopts MCP-server skills (beta) — Nov 25 changelog.** Skills shipped by MCP servers now appear in the `/` menu as `server:skill`, and a new **`PreSkillShellCommand`** hook can refuse a skill or command's inline shell commands as it loads. The changelog also flags that, on/after **Nov 30**, plugin marketplaces in managed `extraKnownMarketplaces` will auto-update by default. ([changelog](https://code.claude.com/docs/en/changelog))
- **MCP reference servers v2.4.0 security update (Nov 11, surfaced as backlog).** Six vulnerabilities fixed across the Filesystem, Git, and Fetch reference servers (one High); corrected minimums are Filesystem `2.3.0`, Git `2026.11.11`, and Fetch `2026.11.11`. Update the package your host actually starts. ([advisory](https://modelcontextprotocol.info/blog/reference-servers-security-update-2026-11))

## New / notable tools and platforms
- **Together AI Hurdle (Nov 25)** — a free agent-evaluation harness that runs the same job dozens of times in a locked-down sandbox and scores every attempt (code checks, forbidden-action guards, an AI judge against a plain-English checklist, and a pass-rate/time/cost results screen). Works with **Claude Code** and **Codex**, aimed at vendors validating whether agents can actually use their API, skills, and docs. ([announcement](https://www.together.ai/blog/introducing-hurdle-run-agent-evals-on-your-api-skills-and-docs))
- **JetBrains Mellum2.1 Instruct (Nov 26)** — open **12B MoE** (2.5B active) coding model under Apache 2.0 that answers directly without chain-of-thought, emitting roughly half the tokens of Mellum2.1 Thinking on coding-agent tasks while scoring nearly as well on SWE-bench Verified; ships with a multi-token-prediction head (up to 1.8× faster). Built for sub-agents, tool loops, and chat. ([blog](https://blog.jetbrains.com/ai/2026/11/mellum2-1-instruct-is-out))
