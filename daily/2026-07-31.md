# 2026-07-31

## Hermes / Hermes-adjacent

- **A new tagged release ships: `v0.19.1` (`v2026.7.30`).** It's the first new tag since `v0.19.0` "Quicksilver" (Jul 20) and rolls up ~2,789 commits / ~4,748 files changed on `main` since then into a stable tag for downstream consumers (Docker images, hosted deployments, fresh installs via `hermes update` or `install.sh`). It is explicitly a patch/stabilization rollup, not a curated feature drop — Nous says full curated release notes covering everything since `v0.19.0` will ship with `v0.20.0`.
  https://github.com/NousResearch/hermes-agent/releases/tag/v2026.7.30
- **A real org-skills sync bug is root-caused and closed: org-shared skills were unusable past the first propose.** `SyncClient.get_refs()`/`get_object()` only ever called the personal `/v1/sync/refs` and `/v1/sync/objects/:hash` endpoints, which are hard-scoped server-side to the caller's own owner — so asking them for an org ref silently returned the caller's *personal* refs instead of an error, and org objects 404'd. `pull_org_skills` resolved `head=None` for a populated org and reported `{"ok": true, "head": null, "updated": []}`, masking two further defects. Fixed by routing org reads through the org endpoints.
  https://github.com/NousResearch/hermes-agent/pull/75237
- **A genuine idle-CPU reliability fix: a minimized, idle Hermes desktop held ~20% CPU forever.** Root cause was process-wide throttling opt-outs (`disable-background-timer-throttling`, `disable-backgrounding-occluded-windows`) plus a static `backgroundThrottling: false` pinning every chat window's `visibilityState` to `'visible'` for its whole life — so visibility-gated backstop polls and clock ticks ran at full cadence 24/7, including on battery. The opt-out is now scoped to only the windows with an active streaming turn.
  https://github.com/NousResearch/hermes-agent/pull/75218
- **TUI composer: image attachments now behave like pastes instead of a disconnected notice line.** Attaching an image used to print a `📎 Attached image: ...` line above the status bar while leaving the composer untouched (and sometimes leaking stray text from an unrelated field). Attachments are now the same `ComposerToken` model as collapsed pastes, so they inherit paste's inline-token ergonomics for free.
  https://github.com/NousResearch/hermes-agent/pull/75210
- Remaining volume today is desktop UI polish riding on the above fixes: opening links clicked in the integrated terminal, middle-click-to-close on non-macOS three-button mice, and closing the last main tab landing on a fresh session instead of doing nothing.

## Broader AI agent ecosystem

- **GitHub Copilot in VS Code's July 2026 releases (v1.127–v1.131) bring a real cross-vendor interoperability move to the Agents window (public preview): sessions in Copilot, Claude, or Codex can now each run in an isolated Git worktree from the same UI**, alongside a redesigned review layout (inline/side-by-side diff toggle, per-file add/delete counts), subagent tracking (model, elapsed time, active tool call), and acting on failed CI checks or new review comments directly from a chat banner. Multi-harness worktree support inside a single vendor's IDE surface is a concrete interoperability signal, not just a UI refresh.
  https://github.blog/changelog/2026-07-30-github-copilot-in-visual-studio-code-july-2026-releases
- **GitHub Copilot in Visual Studio ships a new SDK-based Agent (Preview)**, built on the same GitHub Copilot SDK that powers the Copilot CLI, plus built-in .NET/Azure expert skills (off by default), inline "Review Selection" code review, and org-level custom instructions.
  https://github.blog/changelog/2026-07-30-github-copilot-in-visual-studio-july-update
- **GitHub Models is now fully retired** (playground, model catalog, inference API, and BYOK all removed for every customer, including existing usage), completing the retirement announced Jul 1. Developers needing a model catalog are pointed to Microsoft Foundry or GitHub Copilot. Relevant context for anyone who had prototyped against the GitHub Models inference API.
  https://github.blog/changelog/2026-07-30-github-models-is-now-retired
- No new stable Claude Code release since `2.1.220` (Jul 25); OpenAI Codex CLI remains in alpha churn past stable `0.146.0` (latest: `rust-v0.147.0-alpha.2`, Jul 30) with nothing changelog-worthy yet.
