# 2026-11-27

## Hermes / Hermes-adjacent
- **No new stable release** — v0.23.4 (Nov 24) remains latest. Today's canary (`canary.20261127T064803Z-v0.23.4`, tagged 06:48 UTC) is a larger-than-usual roll (~641 commits since the Nov 25 canary, ~250 of them routine plugin-catalog entries). The meaningful non-catalog clusters:
  - **Gateway stop/restart reliability** — a large batch hardens `/restart` and shutdown: a failed restart no longer blocks later restarts, the stop path preloads its modules from memory (not files an upgrade just replaced), blocked liveness diagnostics are exited cleanly, and host memory-pressure is recorded when the liveness watchdog kills the gateway.
  - **New plugin API `turn_origin`** — plugins can now tell whether Hermes (vs. a user or peer) started the running turn.
  - **Google provider consolidation** — Gemini and Solstice refactors combine into a bundled `google` plugin with a native adapter, plus a "left-core migration" predicate ahead of cutover.
  - **macOS Desktop move-to-Applications** — Desktop offers to move packaged macOS bundles into `/Applications`, with SemVer/stamp ordering, downgrade and dangling-CLI-link guards, and outer-DMG signing + notarization.
  - **File/search/session tooling** — `read_file` gains negative-offset tails and directory listing, `search_files` reports when a content search is the whole answer, and a long `session_search` fix cluster (query honouring, recovery reach, scroll, compaction survival).
  - A macOS Command-Line-Tools **git-stub guard** keeps cron/gateway/CLI from tripping over Apple's stub `git` when real git isn't installed. ([canary](https://github.com/NousResearch/hermes-agent/releases/tag/canary.20261127T064803Z-v0.23.4))
