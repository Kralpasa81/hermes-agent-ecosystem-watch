## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but main-branch work stayed meaningfully active around gateway supervision and Desktop/dashboard reliability.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Profile gateway supervision was tightened for multi-profile and always-on deployments.** The June 15 commits keep the reserved default gateway from following a sticky `active_profile`, register profile gateways without auto-starting them, persist profile gateway desired state, clear stale log locks before startup, and make the profile-gateway log parent writable. Sources: https://github.com/NousResearch/hermes-agent/commit/95715dcb03003eab086eb0494083e6dc1c65f3b3, https://github.com/NousResearch/hermes-agent/commit/40d7c264f0471d8b7fce39ef12d49cb02eb18b0e, https://github.com/NousResearch/hermes-agent/commit/b7709672636f5d65f25790514e64aea65d8d9c3a, https://github.com/NousResearch/hermes-agent/commit/c2b7669ad3dd02232d06cde36f6e56ef04dec970, https://github.com/NousResearch/hermes-agent/commit/61ee2dbfdb407af8a5a649683dc4966272a94b53
- **Dashboard-to-gateway behavior received another reliability pass.** Hermes now pins the machine-dashboard reroute to the machine root instead of `$HOME/.hermes`, and removes an `is_container` check when restarting over the dashboard. Sources: https://github.com/NousResearch/hermes-agent/commit/80f8ffc74c7b8994c9671408df15f10882726882, https://github.com/NousResearch/hermes-agent/commit/4eb0ff639ba905a2175c85121f3ba78f670d127d
- **Windows update/install friction was reduced.** Hermes now kills the running Hermes process before recreating the virtualenv so `_bcrypt.pyd` can be released cleanly on Windows. Source: https://github.com/NousResearch/hermes-agent/commit/f7955137828e43d26bab926f0aacc5302d5fa357
- **Desktop polish continued in a small but practical way.** A hover-reveal trigger was inset past the adjacent scrollbar, reducing accidental UI friction in the native Desktop surface. Source: https://github.com/NousResearch/hermes-agent/commit/8fe334b056d4ab83e51a2abf2ca4d1ac8982770a
