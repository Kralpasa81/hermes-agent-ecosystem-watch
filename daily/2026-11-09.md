# 2026-11-09

## Hermes / Hermes-adjacent
- **Hermes ships an official Security plugin (`hermes-security`, Nov 8).** Built by Hermes engineer Mark S. (@mark_s, CISSP), it reviews a codebase for security bugs end to end: it first maps what an attacker can reach and which inputs the code trusts, then splits the code across parallel subagents, checks every candidate finding against the code, and traces whether an attacker can actually exploit it. With test confirmation enabled, Hermes writes a small reproduction for each finding and runs it in a temporary copy of the repo. Each report records the evidence *and* the findings Hermes ruled out, and exports to SARIF for existing tooling. Runs from chat, the CLI, or the new Security page in Hermes Desktop. ([announcement](https://x.com/NousResearch/status/2119501958981857543))
- **The Hermes Marketplace community tier passed 1,000 plugins (Nov 8).** Teknium confirmed the milestone on X, about a week after the unified marketplace (plugins + skills + connectors) launched; the community tier is browsable at the marketplace filtered to community. A concrete extensibility/interoperability signal for the Hermes plugin surface, alongside the still-running $20k Plugin Hackathon. ([marketplace](https://hermes-agent.nousresearch.com/marketplace?kind=plugins&tier=community))
