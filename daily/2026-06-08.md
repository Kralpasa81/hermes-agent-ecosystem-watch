# 2026-06-08

## Hermes / Hermes-adjacent

- **Hermes Agent still had no newer tagged release after `v2026.6.5`, but June 8 main-branch work contained several operationally meaningful fixes.** The latest release remains `v2026.6.5` / v0.16.0, published after the June 5 Surface Release notes. Source: https://github.com/NousResearch/hermes-agent/releases
- **Tool and working-directory safety received a focused hardening pass.** Hermes added protections to reject the sentinel `TERMINAL_CWD`, anchor worktree edits before a live cwd exists, and read terminal cwd overrides under the raw task id after container collapse. These are practical reliability/safety fixes for tool execution and file edits. Sources: https://github.com/NousResearch/hermes-agent/commit/e45b74583589424970c4af47366464178378e31f, https://github.com/NousResearch/hermes-agent/commit/329c33dac3d1dafe81ffa83e7194f7ff1e734c61
- **Gateway/service replacement behavior was tightened.** Main-branch fixes removed `--replace` from systemd unit templates and made gateway replacement abort if the old PID survives SIGKILL, reducing risk around supervised or systemd-managed gateway restarts. Sources: https://github.com/NousResearch/hermes-agent/commit/4d18717b6c798d4f6bab9e736c6ed10c5a8365f4, https://github.com/NousResearch/hermes-agent/commit/e02f4c03c312adfbea316da57aa248104a26e678
- **Packaging, built-in skill protection, and provider-path reliability also improved.** Notable commits added Nix cold npm build / lockfile verification work, protected load-bearing built-in skills from curator archival or consolidation, retried transient auxiliary transport errors once before fallback, and routed the Codex Responses path through the shared converter. Sources: https://github.com/NousResearch/hermes-agent/commit/d02a59b67997b9533eb786633604b1bec9c24bf9, https://github.com/NousResearch/hermes-agent/commit/8e223b36ed01fb3b5c9f99cfa1c7273a57cdbc47, https://github.com/NousResearch/hermes-agent/commit/02a4d66951984e7e4a656ac0d5162a7a6a1ee8ad, https://github.com/NousResearch/hermes-agent/commit/2789bf4e2591e4f8bc773f4f0ae3c4ac062b9631
