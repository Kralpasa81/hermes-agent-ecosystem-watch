# 2026-10-25

## Hermes / Hermes-adjacent

- ⭐ Hermes fixed a **cron MCP allowlist escalation**: a job that named one MCP server could receive every enabled MCP server because `mcp-` toolset names and bare aliases were compared inconsistently. The fix recognises both forms and preserves `no_mcp`; this is a direct least-privilege improvement for scheduled automation. ([Source](https://github.com/NousResearch/hermes-agent/commit/11cebb30dafd478c7f30818715ba248f24e44212))
- Plugin `ctx.side_question` landed with a capability-and-consent gate for one short, text-only follow-up request using the session's warm context. Follow-up fixes prevent unattended cron/subagent spend, bind leases to a profile, retain parent tool state, and make usage/observer attribution accurate. ([Feature](https://github.com/NousResearch/hermes-agent/commit/a8db83446f1d6be429a9815f5c9dc54befbd3909), [follow-up](https://github.com/NousResearch/hermes-agent/commit/4ea8d23cc9f527332ccb1d55359b27741b6ea51b))
