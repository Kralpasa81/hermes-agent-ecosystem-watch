- OpenAI relaunched Codex (May 2025) as a cloud-based, autonomous coding agent, now powered by GPT-5.5. It can execute full coding tasks, run tests, and operate in parallel within a sandboxed environment. [[Source]](https://openai.com/index/introducing-codex/)

Further integrations with Google, Cognition, and xAI are planned. [[Source]](https://github.blog/news-insights/company-news/pick-your-agent-use-claude-and-codex-on-agent-hq/)

- **Codex Security**: A dedicated AI agent by OpenAI for automated vulnerability detection and remediation in code. [[Source]](https://bhavishyapandit9.substack.com/p/everything-about-codex-the-complete)
