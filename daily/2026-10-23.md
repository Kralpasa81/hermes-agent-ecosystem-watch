# 2026-10-23

## Hermes / Hermes-adjacent

- [Hermes Agent v0.22.5](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.5) is the latest stable patch. It rolls up the v0.22.4-to-v0.22.5 window for CLI/installers, Microsoft Store, Docker, and Hermes Cloud. Notable workflow changes in that window include pluggable subagent delegation backends, `hermes import-agent` / OpenClaw migration, `hermes mcp serve` moving into a plugin, improved sign-in and update recovery, plus experimental webhook-mode MCP events. The project says full curated notes will arrive with v0.23.0.

## Broader AI agent ecosystem

- OpenAI made the [Decisions API](https://openai.com/index/decisions-api/) generally available on October 22. The dedicated GPT-6 Luna endpoint is for bounded routing, classification, and scoring decisions inside applications and agents; it supports text, images, and JSON inputs, with GPT-Live integration and prompt caching.

## New / notable tools and platforms

- **OpenAI Decisions API**: a purpose-built, low-latency decision layer for agent orchestration paths such as choosing an action, retry, route, or escalation. It is not a replacement for a general agent runtime, but is a notable building block for high-volume control loops.

## Starred signals today

- ⭐ **Hermes Agent v0.22.5**: a substantial stable roll-up for all main distribution channels, with meaningful improvements across updates, sign-in, delegation, agent migration, MCP serving, and gateway recovery.
- ⭐ **OpenAI Decisions API GA**: provides a dedicated, structured option for fast decisions in agent workflows rather than using a general-purpose response call for every routing step.
