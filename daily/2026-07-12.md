## Broader AI agent ecosystem

- **Claude Code v2.1.207** (first seen July 11, no parsed date) — the most recent release in Claude Code's July 2026 wave.
  - Auto mode is now default on **Bedrock, Vertex AI, and Foundry** without the `CLAUDE_CODE_ENABLE_AUTO_MODE` opt-in flag. Disable via `disableAutoMode` in settings.
  - Bedrock, Vertex, and Claude Platform on AWS now default to **Claude Opus 4.8**.
  - Key fixes: terminal freeze on streaming long lists/tables/code blocks; spurious prompt-injection warnings on benign system messages; auto-updater no longer overwrites custom launcher scripts/symlinks at `~/.local/bin/claude`; compound `cd` commands no longer prompt for permission when the only output redirect is `/dev/null`; OAuth MCP servers now re-authenticate cleanly after a failed token refresh; Remote Control task-status updates no longer get lost on network interruption/credential refresh.
  - Security: plugin option values (`pluginConfigs`) are now only read from user/`--settings`/managed settings, not from project-level `.claude/settings.json`; shell-form `${user_config.*}` variables in plugin hooks rejected (shell-injection fix).
  - Source: https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md

- **Claude Code Week 28 (July 6–10)** — published July 10, covers the week's headline features:
  - **Built-in desktop browser**: Claude Code on Desktop can now pull up docs, designs, and external sites, reading and interacting with pages the same way it does with local dev server previews. Sandboxed and configurable (persistent or ephemeral sessions; safety classifiers on external sites).
  - **`/doctor` is now a full setup checkup**: finds and fixes installation issues, flags unused skills/MCP servers/plugins by context cost, deduplicates CLAUDE.md files, proposes trimming content Claude could derive from the codebase, and flags slow hooks. Alias: `/checkup`.
  - Auto mode blocks tampering with session transcript files; asks before running `rm -rf` on unresolved variables.
  - `/commit-push-pr` now auto-allows `git push` to the repo's configured push remote in addition to `origin`.
  - Gateway: `/login` now supports Anthropic-operated public gateway endpoints.
  - Agent view rows now show a colored state word and a classifier-written headline rather than raw tool-call text.
  - Auto-update binary downloads stream to disk instead of buffering in memory — peak updater memory cut by ~400 MB.
  - Source: https://code.claude.com/docs/en/whats-new/2026-w28

- **MCP 2026-07-28 RC** — validation window continues; **16 days to final spec** (July 28). No new changes to the RC itself; SDK maintainers are in their 10-week validation period. Key recall: stateless HTTP core (no `initialize` handshake, no `Mcp-Session-Id`), MCP Apps, Tasks extension, OAuth/OIDC hardening, deprecation policy with 12-month window.
  - Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
