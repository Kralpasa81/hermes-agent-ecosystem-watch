# 2026-07-02

## Hermes / Hermes-adjacent

- **Hermes Agent `v0.18.0` / `v2026.7.1` — “The Judgment Release”:** Hermes shipped a major tagged release on July 1. The release notes report ~1,720 commits, 998 merged PRs, 2,215 files changed, 949 issues closed, 370+ community contributors, and a P0/P1 clean sweep. The most workflow-relevant highlights include first-class Mixture-of-Agents model selection, visible reference-model reasoning with streamed aggregation, stronger evidence-based completion checks, `/goal` completion contracts, `/learn` + `/journey` improvements, gateway scale-to-zero / drain coordination, Desktop coding-project work, memory-graph improvements, and background subagent fan-out. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.7.1
- **Post-release multi-profile stale-runtime issue:** A new Hermes issue reports that non-default profile runtimes can remain stale after updating to `v0.18.0`, causing an `is_output_cap_error` import mismatch while the default profile reports up to date. This is a practical upgrade watch item for users running profile-specific gateways or dashboards. Source: https://github.com/NousResearch/hermes-agent/issues/56717
