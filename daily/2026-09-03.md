## Broader AI agent ecosystem

- **Claude Fable 5.1 and Claude Mythos 5.1 launched (Sep 1, 2026)**  
  Anthropic's most advanced generally available models for coding and knowledge work. Fable 5.1 targets long-horizon, autonomous agent tasks; Mythos 5.1 is positioned as the frontier research/knowledge tier. Both are now in the Claude API and available in GitHub Copilot (as of Sep 1) and via Claude Code.  
  Source: https://www.anthropic.com/claude-fable-and-mythos-5-1

- **Microsoft MAI-Code-1.1-Flash rolling out in GitHub Copilot**  
  Microsoft's updated coding model adds native vision support (image understanding) alongside improved coding quality, better instruction following, and tool use — with lower cost and token consumption than MAI-Code-1-Flash. Rolling out to VS Code, Visual Studio, JetBrains, Copilot CLI, GitHub Mobile, and all other Copilot surfaces. MAI-Code-1-Flash will be deprecated on September 10, 2026.  
  Source: https://github.blog/changelog/ | https://www.neowin.net/news/microsoft-releases-mai-code-11-flash-coding-model-to-better-compete-with-chinese-models/

- **Copilot CLI: air-gapped GHES support**  
  Copilot CLI now works in air-gapped GitHub Enterprise Server environments with centralized model provider setup — meaningful for regulated or network-restricted enterprise deployments.  
  Source: https://x.com/GHchangelog

- **OpenAI DevDay 2026 confirmed: September 29, San Francisco**  
  OpenAI's annual developer conference is set for September 29. Applications open; global "DevDay Exchange" events planned for builders worldwide. The conference is expected to feature deep technical sessions on the current API/Codex/GPT-5.6 stack.  
  Source: https://devday.openai.com/

- **GPT-5.6 Sol: 20%+ price reduction (Aug 21, 2026)**  
  Input price dropped from $5 → $4 per million tokens; output from $30 → $20 per million tokens (33% reduction). Promotional pricing valid through at least November 21, 2026. Applies to API, Codex credits, and ChatGPT Work.  
  Source: https://community.openai.com/t/20-price-reduction-for-gpt-5-6-sol-api-codex-credits-and-chatgpt-work/1391726
