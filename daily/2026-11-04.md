# 2026-11-04

## Hermes / Hermes-adjacent
- **Hermes Agent v0.22.7 (Nov 3, 2026).** Latest stable patch rolls up ~174 PRs (581 non-merge commits, 554 files, +24,012 / −3,144) into the GitHub release, Microsoft Store app, Docker, and Hermes Cloud. Undocumented-but-shipped items include: opt-in lead routing for Desktop Group Chats (with a Lead badge on the room header), cron jobs that post into Group Chats, room purpose and shared notes, group rooms laid out in one chat column with per-member live state, pinned Kanban boards as quick-switch tabs, `$$TeX$$` and mermaid diagram rendering through Pele, a Desktop update error box that shows the failed update's output with a report link, Web Access naming the step Start is on with a running clock, Telegram on Team Gateway via account linking, an opt-in Slack `thread_followup_silence`, a Daybreak switch for catalog-listed ChatGPT subscription models, and new plugin-catalog entries. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.7))
- **Hermes Agent v0.22.6 (Nov 2, 2026).** A larger patch rolling up ~776 PRs (3,448 non-merge commits, 4,316 files) since v0.22.5. Notable shipped items: the webapp served from the gateway's own listener (`hermes webapp`, a Desktop Web Access pane to open it on the network or behind Nous sign-in, and Desktop plugins loading in a browser tab), `/model reset`, per-skill locks against autonomous writes (lockable from the Desktop Capabilities pane), opt-in prepared compaction (`compression.prepare_ahead`), `hermes cron cancel` plus a per-job missed-run policy and a Stop button in the Desktop cron editor, `/delegation` choices saved for the next session, `hermes migrate` for Grok Bot/OpenBot users, opt-in OS-keychain storage for the vault key, `requires_hermes` enforced at plugin install/update, agent-picked ElevenLabs voices, a `pre_llm_call` hook that can block a turn before inference, Desktop group-chat rename/disband/mentions/attachment paste, Telegram video notes, Slack emoji reactions, and resumable package downloads. ([release](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.6))
- _Both releases shipped after the prior note (2026-11-02, which still listed v0.22.5 as latest). Their combined window is the largest roll-up since v0.22.0, and full curated notes for both are deferred to v0.23.0._

## Broader AI agent ecosystem
- **Mistral Large 4 ("Le Chonk") open weights (Oct 29, 2026; recorded retroactively).** Mistral released open weights for a 1-trillion-parameter multimodal model targeting agentic coding and cybersecurity. It leads open-weight agentic-coding benchmarks (Terminal-Bench 4.0: 41% vs GLM-5.3's 40%) while using ~47% fewer tokens per task, with three reasoning modes and European-trained, sovereign-AI positioning. Weights are on Hugging Face, deployable via vLLM/SGLang. ([Mistral](https://mistral.ai/news/mistral-large-4-oss/))
- **LangChain Managed Deep Agents v0.10 (Oct 29, 2026; recorded retroactively).** Adds browser use (agents can operate websites with no API, with a hand-off when a site needs a login) and asynchronous subagents (long tasks run in the background while the agent keeps the conversation), now in public beta on LangSmith. ([LangChain](https://www.langchain.com/blog/managed-deep-agents-browser-use-and-asynchronous-subagents))
