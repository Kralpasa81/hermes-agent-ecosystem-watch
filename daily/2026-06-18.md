# 2026-06-18

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but June 18 main-branch activity was unusually high-signal for hosted, relay, dashboard, gateway, and unattended-operation workflows.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Relay support moved toward zero-touch managed gateways.** Hermes added connector↔gateway channel authentication, a signed-HTTP inbound receiver, and an enrollment CLI, then added managed-boot self-provisioning so managed agents can obtain relay credentials in process memory at startup without a human enrollment token or disk-written secret. Sources: https://github.com/NousResearch/hermes-agent/pull/48147, https://github.com/NousResearch/hermes-agent/pull/48242
- **Hosted dashboard backup/restore paths were hardened.** Dashboard uploads now use streaming multipart instead of base64 JSON to avoid proxy-size/time-out failures, and `hermes import` now preserves volatile runtime files such as `gateway_state.json`, PID files, locks, and `processes.json` instead of overwriting a live instance with source-machine state. Sources: https://github.com/NousResearch/hermes-agent/pull/47663, https://github.com/NousResearch/hermes-agent/pull/48243
- **Dashboard, Docker, Desktop, and update reliability improved.** The Chat tab can recover in place after a session exits, supervised Docker gateways run with `--replace` to take over stale holders, and install-method stamps are now scoped to the code tree rather than shared `$HERMES_HOME`, fixing host/Desktop versus Docker update contamination. Sources: https://github.com/NousResearch/hermes-agent/pull/47674, https://github.com/NousResearch/hermes-agent/pull/47555, https://github.com/NousResearch/hermes-agent/pull/48188
- **Skills and memory setup received practical operator-facing upgrades.** Hermes now exposes `hermes skills list-modified` and `hermes skills diff <name>` for user-modified bundled skills, and `hermes memory setup` was refreshed for OpenViking profile discovery, local startup, health/auth validation, safer secret-file handling, and atomic OpenViking config writes. Sources: https://github.com/NousResearch/hermes-agent/pull/48286, https://github.com/NousResearch/hermes-agent/pull/48293, https://github.com/NousResearch/hermes-agent/pull/48262, https://github.com/NousResearch/hermes-agent/pull/48265
- **Provider/tool reliability fixes landed for real agent loops.** Manual command allowlist globs such as `podman *` are now honored after hardline safety floors, xAI Responses can swap Hermes' client-side `web_search` function to xAI's native server-side `web_search` built-in, and empty-name phantom tool-call loops no longer dump the whole tool catalog on every retry. Sources: https://github.com/NousResearch/hermes-agent/pull/43051, https://github.com/NousResearch/hermes-agent/pull/48108, https://github.com/NousResearch/hermes-agent/pull/48109
- **Observability cleanup continued.** Langfuse trace state is now scoped and bounded so interrupted or tool-ending turns do not leave unbounded `_TRACE_STATE` growth. Source: https://github.com/NousResearch/hermes-agent/pull/48292

## Broader AI agent ecosystem

- **OpenAI Codex CLI `0.141.0` shipped as a stable release.** The release adds authenticated end-to-end encrypted Noise relay channels for remote executors, better cross-platform remote execution path/shell preservation, per-thread stdio MCP activation from selected executor plugins, plugin discovery/catalog improvements, app-server thread/import/rate-limit-credit APIs, realtime controls, and multiple reliability fixes. Source: https://github.com/openai/codex/releases/tag/rust-v0.141.0
- **Claude Code `v2.1.181` shipped a large maintenance release.** Notable changes include `/config key=value`, `sandbox.allowAppleEvents`, `CLAUDE_CLIENT_PRESENCE_FILE`, Bun 1.4, better long-paragraph streaming, auto-retry for mid-thinking connection drops, fixes for truncated writes on network/cloud-synced folders, startup regressions, MCP `tools/list` failure reporting, and subagent/depth handling. Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.181
- **GitHub Copilot had a major desktop/discovery wave.** The GitHub Copilot app is now generally available for macOS, Windows, and Linux; Agent Finder is available across Copilot plans for registry-based discovery of MCP servers, skills, canvases, agents, and tools using the open Agentic Resource Discovery specification; and Copilot Chat auto mode is now available for all users. Sources: https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available/, https://github.blog/changelog/2026-06-17-agent-finder-for-github-copilot-now-available/, https://github.blog/changelog/2026-06-17-auto-mode-in-copilot-chat-available-for-all-users/
