## New / notable tools and platforms
- **Self-hosted Claude Managed Agents (private beta, Nov 12).** Anthropic now lets enterprises run the entire Managed Agents service — the agent harness, sandboxes, and session history — on their own cloud or on-premise infrastructure, not just the isolated sandbox. Same core APIs, with model choice (Anthropic or another provider), keeping agent credentials and session data inside the customer's perimeter. A meaningful control-plane/access expansion for enterprise agent deployment. ([docs](https://platform.claude.com/docs/en/managed-agents/self-hosted), [Help Net Security](https://www.helpnetsecurity.com/2026/11/12/anthropic-self-hosted-claude-managed-agents/))
