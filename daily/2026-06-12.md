# 2026-06-12

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but June 12 main-branch activity was meaningful for plugins, messaging gateways, MCP compatibility, Desktop reliability, approvals, memory, and coding safety.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Slack plugin interactivity moved from “post only” toward bidirectional workflows.** Hermes added `PluginContext.register_slack_action_handler(action_id, callback)` so plugins can receive Slack Block Kit actions, while follow-up registry fixes make shared hook/middleware/tool attribution accurate and clear stale platform names on force rediscovery. Sources: https://github.com/NousResearch/hermes-agent/pull/44664, https://github.com/NousResearch/hermes-agent/pull/44674
- **Gateway and messaging reliability improved across attachments, reactions, and Photon.** Main branch added document classification for Signal, SimpleX, and email attachments; exposed `action='unreact'` in `send_message`; added agent-facing Photon emoji reactions; normalized Photon DM chat keys; and hardened Photon sidecar restart behavior so gateway restarts do not leave the sidecar orphaned on its port. Sources: https://github.com/NousResearch/hermes-agent/commit/8207ae888dfa, https://github.com/NousResearch/hermes-agent/commit/1e29ab38c739, https://github.com/NousResearch/hermes-agent/commit/74180ebf0b1c, https://github.com/NousResearch/hermes-agent/commit/f03f161b39d6, https://github.com/NousResearch/hermes-agent/commit/05470aa1b602, https://github.com/NousResearch/hermes-agent/commit/156f4fba923e, https://github.com/NousResearch/hermes-agent/commit/a652131c421b
- **MCP and tool-schema compatibility received practical fixes.** Hermes now capability-gates `tools/list` so prompt-only or resource-only MCP servers can connect, and strips invalid `default` values from `$ref` nodes in tool schemas. These are small but important interoperability fixes for mixed MCP/tool ecosystems. Sources: https://github.com/NousResearch/hermes-agent/commit/5affecb44379, https://github.com/NousResearch/hermes-agent/commit/b2d151abe249
- **CLI/TUI approval UX became more auditable and readable.** Resolved approval/clarify prompts are now persisted in scrollback, and long approval commands/wrapped preview hints are handled better in CLI/TUI prompts and overlays. Sources: https://github.com/NousResearch/hermes-agent/pull/44702, https://github.com/NousResearch/hermes-agent/commit/d6df38bb6b0a, https://github.com/NousResearch/hermes-agent/commit/b3f5e17bb9ca
- **Desktop and packaging polish continued after the Surface release.** Notable fixes include collecting and persisting API keys for custom OpenAI endpoints, selectable file-preview source and markdown, bundled JetBrains Mono for the terminal pane, RTL/bidi text direction auto-detection in chat, a tool-row copy affordance, and Nix staging for `node-pty` in the desktop app. Sources: https://github.com/NousResearch/hermes-agent/commit/4ddb03390a95, https://github.com/NousResearch/hermes-agent/commit/24f74eb88853, https://github.com/NousResearch/hermes-agent/commit/6e41ca956bbf, https://github.com/NousResearch/hermes-agent/commit/6c00077d3838, https://github.com/NousResearch/hermes-agent/pull/44627, https://github.com/NousResearch/hermes-agent/commit/906bee9cf791
- **Memory, compression, and coding safety were tightened.** Hermes flattens multimodal content before provider sync, strips `MEDIA` directives from compressor summarizer input, focuses automatic compression on recent user turns, teaches coding agents that terminal environment state persists, and avoids exposing the primary worktree root in context to reduce wrong-worktree edits. Sources: https://github.com/NousResearch/hermes-agent/pull/44738, https://github.com/NousResearch/hermes-agent/commit/286ecd26d877, https://github.com/NousResearch/hermes-agent/commit/434c684bfa32, https://github.com/NousResearch/hermes-agent/commit/ab06ef8ed615, https://github.com/NousResearch/hermes-agent/commit/96cc7ee1e3cf

## Broader AI agent ecosystem

- **Claude Code `2.1.175` / `2.1.174` focused on managed model governance, background-session isolation, Bedrock correctness, and usage observability.** The new `enforceAvailableModels` managed setting constrains Default model resolution and prevents user/project settings from widening managed allowlists; `2.1.174` also fixes background sessions inheriting another session’s `ANTHROPIC_*` provider environment, Bedrock GovCloud inference-profile prefixing, `/model` picker correctness, skill hot-reload chatter, and adds VS Code usage attribution across cache misses, long context, subagents, skills, agents, plugins, and MCP. Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- **OpenAI Codex app `26.609` added Developer mode for browser use and broader automation/app improvements.** The June 11 Codex changelog says Developer mode gives Codex controlled Chrome DevTools Protocol access for network, console, runtime, and page-state debugging; browser use is up to 2x faster via CDP and DOM snapshot optimizations; `/init` is available in the app composer; Computer Use availability and access controls expanded; scheduled automations now honor selected approval mode. Source: https://developers.openai.com/codex/changelog/
- **GitHub Agentic Workflows entered public preview and also gained a lower-risk auth path.** GitHub says teams can define reasoning-based engineering automations in natural-language Markdown that compile to standard GitHub Actions YAML, with read-only defaults, sandboxing, integrity filters, firewalling, safe outputs, and threat detection; a companion update lets workflows use `GITHUB_TOKEN` instead of long-lived PATs, with org billing via `copilot-requests: write`. Sources: https://github.blog/changelog/2026-06-11-github-agentic-workflows-is-now-in-public-preview, https://github.blog/changelog/2026-06-11-agentic-workflows-no-longer-need-a-personal-access-token
- **Copilot CLI configuration became more operator-friendly.** The new `/settings` command provides a searchable, schema-driven configuration surface with inline setting, reset, tab completion, validation, and editor fallback for complex JSON settings. Source: https://github.blog/changelog/2026-06-11-copilot-cli-configure-everything-from-one-place-with-settings
- **No newer official MCP spec announcement beyond the already-captured `2026-07-28` release candidate was found during today’s check.** The high-signal MCP item remains the stateless-core / Apps / Tasks / OAuth-aligned authorization release candidate. Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate
