# 2026-11-01

## Hermes / Hermes-adjacent
- **Approval-prompt display hardening lands on `main`.** A cluster of Nov 1 commits makes dangerous hidden content visible before a human approves a command. `sanitize_command_for_display()` / `redact_approval_display()` now surface zero-width and bidi-override characters, ANSI/OSC escapes, carriage returns, and runs of padding as explicit `\uXXXX` / `\xNN` escapes, applied at every approval mint site (CLI prompt, gateway notify payload, `execute_code` pending body, plugin approval transports). A companion fix makes the TUI page long approval commands so every line is reviewable (previously line 11+ never reached the screen), and keeps `clarify` choices that sanitize to the same display distinct. Display-only: the executed command and allowlist keys are unchanged. No new stable release shipped; latest remains [v0.22.5](https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.5). ([feat](https://github.com/NousResearch/hermes-agent/commit/3f5612cde62556d0b73558230f4acb0e98279d83), [tui paging](https://github.com/NousResearch/hermes-agent/commit/6513a4f591fdf5f8f8ad9111b10f2c5eabcf441f), [clarify](https://github.com/NousResearch/hermes-agent/commit/a4994d4ead8f9c915b485cec5689909b349a49df))

## Broader AI agent ecosystem
- **GitHub Universe 2026: Copilot Fusion GA and a rebuilt Copilot surface (Oct 28).** Copilot Fusion, GitHub's multi-model routing/orchestration layer, reached general availability. Fusion Max scored within two points of Claude Code + Opus 5.5 Max on the Artificial Analysis Coding Agent Index at roughly half the cost and ~40% less time per task. GitHub also shipped the new **GitHub Copilot app** (an agentic, issue-to-merge surface), **Copilot projects** (goal-based, multi-repo parallel agent sessions, public preview), and **Copilot code review Max**. ([GitHub](https://github.blog/news-insights/company-news/github-universe-2026-evolving-every-layer-of-the-stack/), [unite.ai](https://www.unite.ai/github-makes-copilot-fusion-generally-available-at-universe-2026/))
