# 2026-06-20

## Hermes / Hermes-adjacent

- **Hermes Agent `v0.17.0` / `v2026.6.19` (“The Reach Release”) is now the primary Hermes signal.** The release was published on June 19 and spans roughly 1,475 commits, ~800 merged PRs, 1,693 changed files, 300+ closed issues, and 245 community contributors since v0.16.0. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Hermes gained major new reach across communication and agent-network surfaces.** The release adds iMessage support through Photon Spectrum with device-code login and no Mac relay, plus a bundled Raft gateway adapter that lets Raft wake Hermes through a metadata-only wake-channel bridge. Sources: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19, https://raft.build/
- **Background / async subagents are now a release-highlighted workflow capability.** `delegate_task(background=true)` can return a handle immediately while the delegated agent continues running, then re-enters the conversation with the result when complete. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Automation Blueprints make scheduled work easier to configure without hand-writing cron.** One blueprint can render as a dashboard form, slash command, conversation flow, or docs catalog entry, which is directly relevant to Hermes cron and scheduled-agent usage. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **The release deepens multimodal, memory, skills, and provider capability.** `image_generate` now supports image-to-image editing; the `memory` tool supports atomic add/replace/remove batches against the final character budget; the skill curator no longer spends aux-model tokens on routine consolidation unless opted in; and `grok-composer-2.5-fast` is available through xAI OAuth with a 200k context window. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19
- **Desktop, dashboard, and gateway surfaces moved from post-release hardening into a broader capability release.** Highlights include live subagent watch-windows, native OS notifications, rebindable shortcuts, per-model composer presets, full dashboard profile builder, Skills Hub browser rehaul, secure dashboard login, an official WhatsApp Business Cloud API adapter, Telegram Bot API 10.1 rich messages, and continued hosted/dashboard reliability work. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.19

Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.183

Sources: https://developers.openai.com/codex/changelog, https://github.com/openai/codex/releases/tag/rust-v0.141.0

Source: https://github.blog/changelog/2026-06-19-ai-credits-consumed-per-user-now-in-the-copilot-usage-metrics-api/

Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
