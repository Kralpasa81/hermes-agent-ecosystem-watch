# 2026-06-07

## Hermes / Hermes-adjacent

- **Hermes Agent had no newer tagged release after `v2026.6.5`, but main-branch follow-up work stayed very active around Desktop and admin workflows.** The strongest post-release signal is cron becoming a more first-class graphical surface: the desktop/dashboard backend can fire cron jobs, cron sessions were split into their own sidebar section, sessions are titled from the job rather than the injected scheduling hint, cron jobs became a first-class sidebar entity, and cron overlay mutations now sync the sidebar immediately. Sources: https://github.com/NousResearch/hermes-agent/releases, https://github.com/NousResearch/hermes-agent/commit/3e2d758, https://github.com/NousResearch/hermes-agent/commit/628f904, https://github.com/NousResearch/hermes-agent/commit/ad0f6db, https://github.com/NousResearch/hermes-agent/commit/471a5fc, https://github.com/NousResearch/hermes-agent/commit/1238d08
- **The Desktop/dashboard configuration surface continued to mature after the Surface Release.** Notable changes added full tool-backend configuration in the GUI, a rehauled Skills Hub browser with connected hubs / featured previews / security scan, provider and model menus sourced from `hermes model`, and GUI-triggered post-setup installs for tool backends. Sources: https://github.com/NousResearch/hermes-agent/commit/2bf0a6e, https://github.com/NousResearch/hermes-agent/commit/56236b1, https://github.com/NousResearch/hermes-agent/commit/e8c837c, https://github.com/NousResearch/hermes-agent/commit/9752434
- **Reliability and safety hardening stayed focused on real unattended-use edges.** Main-branch fixes covered Windows gateway process reliability and deep status probes, absolute-path PowerShell bootstrap resolution, Unicode-safe gateway stderr handling on Windows, Bitwarden zip-slip prevention, `skill_view` path-traversal blocking, memory-tool name-shadowing rejection, custom-provider model metadata preservation during config migration, remote SSH CWD preservation, and avoiding mid-session lazy-install prompts under prompt-toolkit. Sources: https://github.com/NousResearch/hermes-agent/commit/fc086da, https://github.com/NousResearch/hermes-agent/commit/8720023, https://github.com/NousResearch/hermes-agent/commit/b08662b, https://github.com/NousResearch/hermes-agent/commit/8f7567c, https://github.com/NousResearch/hermes-agent/commit/56f833e, https://github.com/NousResearch/hermes-agent/commit/fe8920d, https://github.com/NousResearch/hermes-agent/commit/887295b, https://github.com/NousResearch/hermes-agent/commit/0e0d704, https://github.com/NousResearch/hermes-agent/commit/d47f919
