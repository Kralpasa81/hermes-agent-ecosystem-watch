# 2026-06-10

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5`, but June 10 main-branch activity was high signal for skills, memory safety, Desktop, gateway, and provider reliability.** The latest tagged release remains `v2026.6.5` / v0.16.0. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Skills browsing became more operator-friendly and bounded.** Hermes added live per-source progress while browsing skills, constrained ClawHub catalog walking to the requested page on cold start, and honored overall timeouts during catalog walks. This matters for Skills Hub usability and for keeping background catalog work from becoming noisy or unbounded. Sources: https://github.com/NousResearch/hermes-agent/commit/298bb93d397f, https://github.com/NousResearch/hermes-agent/commit/eee1da45f074, https://github.com/NousResearch/hermes-agent/commit/105625d650df
- **Memory and skill writes gained clearer approval semantics.** Main branch replaced the older tri-state write mode with a boolean `write_approval` defaulting off, and added an approve/deny gate for memory + skill writes. This is high-signal safety work for unattended agents that can persist knowledge or create/update skills. Sources: https://github.com/NousResearch/hermes-agent/commit/095f526b112e, https://github.com/NousResearch/hermes-agent/commit/96af61b6ef93
- **Desktop and remote-session polish continued after the Surface release.** Notable changes include opening any chat in its own window, Mac-style session switching, VS Code Marketplace theme installation, a resizable VS Code-themed terminal pane, honoring the default project directory for new sessions, staging dropped files into a remote session workspace, friendlier remote-attachment cap feedback, and session recovery after sleep/wake or WebSocket reconnect. Sources: https://github.com/NousResearch/hermes-agent/commit/b96bd4808dab, https://github.com/NousResearch/hermes-agent/commit/ab5f1a1f1141, https://github.com/NousResearch/hermes-agent/commit/27a321157970, https://github.com/NousResearch/hermes-agent/commit/8f73d0d945d5, https://github.com/NousResearch/hermes-agent/commit/1770263cccf7, https://github.com/NousResearch/hermes-agent/commit/4906dcfc256b, https://github.com/NousResearch/hermes-agent/commit/29147afd637d, https://github.com/NousResearch/hermes-agent/commit/8d71c3891970
- **Gateway, cron, dashboard auth, and provider handling were hardened.** Hermes added gateway auto-start after container restart via a planned-stop marker, repaired cron ownership on container restart, fixed OAuth-gated dashboard token endpoints, ranked explicit web credentials above managed-gateway probing, required confirmation for expensive model selections, and sent `max_completion_tokens` for newer OpenAI-family models on custom endpoints. Sources: https://github.com/NousResearch/hermes-agent/commit/5cf6e28a2f4a, https://github.com/NousResearch/hermes-agent/commit/702f4df194ff, https://github.com/NousResearch/hermes-agent/commit/63a421d4c0e0, https://github.com/NousResearch/hermes-agent/commit/383d44bc9a9e, https://github.com/NousResearch/hermes-agent/commit/af978ecb17ef, https://github.com/NousResearch/hermes-agent/commit/19c07c40379b
- **Model/provider metadata moved with the wider ecosystem.** Hermes added Anthropic `claude-fable-5` to provider and curated model lists, defaulted new Claude models to the modern thinking contract, and corrected MiniMax M3 context metadata to prefer the hardcoded 1M window over stale probes. Sources: https://github.com/NousResearch/hermes-agent/commit/d7886da08c72, https://github.com/NousResearch/hermes-agent/commit/ff9c110d5a2e, https://github.com/NousResearch/hermes-agent/commit/1febb0824000, https://github.com/NousResearch/hermes-agent/commit/5a4297a11a83

## Broader AI agent ecosystem

- **Anthropic announced Claude Fable 5 and Claude Mythos 5, and Claude Code `2.1.170` exposes Fable 5.** Anthropic positions Fable 5 as a generally available Mythos-class model for long-horizon coding and knowledge work, while Mythos 5 is a trusted-access version for selected high-risk domains. Claude Code `2.1.170` adds access to Fable 5 and fixes transcript saving for sessions launched from VS Code integrated terminals or shells inheriting Claude Code environment variables. Sources: https://www.anthropic.com/news/claude-fable-5-mythos-5, https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- **GitHub made Claude Fable 5 generally available in Copilot with governance caveats.** It is available across Copilot surfaces for Pro+, Max, Business, and Enterprise plans, but Business/Enterprise admins must enable a policy that is off by default; GitHub also calls out a Fable-specific 30-day Anthropic prompt/output retention requirement for safety classifiers. Source: https://github.blog/changelog/2026-06-09-claude-fable-5-is-generally-available-for-github-copilot
- **GitHub made security validation for third-party coding agents generally available.** Code generated by third-party agents such as Claude and OpenAI Codex can now receive the same validation as Copilot cloud agent: CodeQL analysis, dependency checks against the GitHub Advisory Database, and secret scanning before a PR is finalized. Source: https://github.blog/changelog/2026-06-09-security-validation-for-third-party-coding-agents
- **OpenAI Codex Mobile gained more serious agent-workflow controls in ChatGPT for iOS `1.2026.153`.** The Codex changelog lists branch selection, worktree creation, environment setup scripts for new threads, a Codex profile screen with usage/token activity, `/goal`, inline review comments, side chat from selected transcript text, latest-prompt editing, better Windows-host attachment support, and inline skills/plugins in the composer. Source: https://developers.openai.com/codex/changelog
- **No new official MCP spec update beyond the already-captured 2026-07-28 release candidate was found during today’s check.** The current high-signal MCP item remains the stateless-core / Apps / Tasks / authorization-hardening release candidate recorded earlier. Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate
