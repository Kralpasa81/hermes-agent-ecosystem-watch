# 2026-06-09

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5`, but June 9 main-branch activity was high signal for desktop, gateway, model, and messaging reliability.** The latest tagged release remains `v2026.6.5` / v0.16.0. Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Remote-gateway file attachments moved forward.** Hermes added `file.attach` handling across Desktop and the TUI gateway server, with tests covering prompt actions and gateway behavior. This matters because remote Desktop sessions need file attachment flows that work without assuming local-only file paths. Source: https://github.com/NousResearch/hermes-agent/commit/dbbd1d4d050146c8e2d0cd01eaa8543993dd98f9
- **Recommended model handling became more resilient.** Hermes now persists Nous recommended models to disk and falls back to the cached data when Portal lookup fails; the curated OpenRouter list also added `laguna-m.1` and `nemotron-3-ultra`. This is a practical reliability improvement for model selection and offline/partial-outage startup paths. Sources: https://github.com/NousResearch/hermes-agent/commit/e687292eb4fdc08a3ea3354d6ca3015ada84fd95, https://github.com/NousResearch/hermes-agent/commit/c4066091cacba42d5afdcceb0b5a87e515019e86
- **TUI and gateway ergonomics continued to tighten.** A TUI fix now applies terminal backend config before launch, and a merged gateway PR added a per-platform `terminal_progress` knob so terminal command progress can stay compact in chat surfaces. Sources: https://github.com/NousResearch/hermes-agent/commit/f8adefdebf082047527a5fe628c0a4c6f3906a57, https://github.com/NousResearch/hermes-agent/pull/42638
- **Photon messaging received meaningful adapter work.** Hermes added voice message support to the Photon adapter and migrated Photon user API calls to the Spectrum backend. This is Hermes-adjacent because messaging gateways remain a core path for always-on agent usage. Sources: https://github.com/NousResearch/hermes-agent/commit/dbf2470d467b7b4665e96ad8dd1e8e01c189c405, https://github.com/NousResearch/hermes-agent/commit/03376589049a1877cb9dd2f07fac8f49a7c6f222
- **Watch item:** a new issue reports MCP tools not being discovered in Desktop/Dashboard mode when `start_server()` bypasses the MCP discovery thread. It is not treated as a confirmed fix yet, but it is important to monitor because MCP discovery is central to Desktop/dashboard workflows. Source: https://github.com/NousResearch/hermes-agent/issues/42694

## Broader AI agent ecosystem

- **OpenAI Codex CLI `0.138.0` shipped with Desktop handoff and automation-oriented plugin output.** The release adds `/app` handoff from CLI threads into Codex Desktop on macOS/native Windows, Windows workspace launches into Desktop, better local/generated image file references, v2 personal access token support, token-usage access for app-server integrations, richer plugin JSON output, and startup/MCP credential resilience fixes. Sources: https://developers.openai.com/codex/changelog, https://github.com/openai/codex/releases/tag/rust-v0.138.0
- **Claude Code `2.1.169` added a troubleshooting/safety mode and stronger policy reliability.** Notable changes include `--safe-mode` / `CLAUDE_CODE_SAFE_MODE` to start with customizations disabled, `/cd` for moving a session without breaking prompt cache, `disableBundledSkills`, more reliable enterprise MCP allow/deny enforcement, improved background-session state, and idle timeout restoration for stalled Vertex/Foundry streams. Source: https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md
- **No new official high-signal GitHub Copilot or MCP announcement was found for June 9 during today’s check.** The important Copilot and MCP items remain the June 2–6 wave already captured in previous notes.
