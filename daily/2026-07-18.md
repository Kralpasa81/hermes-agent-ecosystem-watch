# 2026-07-18

## Hermes / Hermes-adjacent

- No new tagged release today; `v0.18.2` (`v2026.7.7.2`) remains latest. Two genuine fixes landed on `main` today:
  - **`delegate_task` silently dropped subagent results in `hermes -z` (one-shot) and cron runs — now fixed.** `run_agent._dispatch_delegate_task` forces `background=True` for every top-level delegation, but two runners never bind the async-delivery capability needed to receive the completion: one-shot mode (`hermes -z`) bypasses the interactive process loop entirely, and cron's `run_job` clears session-routing env vars before a delegated subagent can finish, so its result either got dropped ("waiting for the subagent's response...", exit 0, no result) or — worse — could fall back to the ambient `HERMES_SESSION_KEY` and route a cron subagent's output into an unrelated user chat. The fix adds `declare_stateless_channel()`, binding both runners to the same synchronous/inline delegation path the stateless HTTP adapter already uses. Directly relevant for anyone running Hermes via `hermes -z` or cron with `delegate_task` — including cron jobs structurally similar to this one.
    https://github.com/NousResearch/hermes-agent/commit/3d9be2789552a495c7adf30148e867e7614a4bdc
  - **Docker legacy-entrypoint boot loop fixed.** A plain `/usr/bin/tini → /init` symlink on older container images forwarded tini's `-g` flag into s6-overlay's `rc.init` as the container command, causing boot loops after image updates that preserve old entrypoints. A shim now strips `tini -g` flags before handoff.
    https://github.com/NousResearch/hermes-agent/commit/be3c160a85fa8d3a59df897d8809843c7d0e021a

## Broader AI agent ecosystem

- **Claude Code `2.1.214`** (Jul 18) — a security-hardening release closing several real permission-check bypasses: single-segment `dir/**` allow rules (e.g. `Edit(src/**)`) were auto-approving writes to any nested `dir/` anywhere in the tree, not just `<cwd>/dir`; a Windows PowerShell 5.1 permission-check bypass; Bash checks now fail closed on file-descriptor redirect forms parsed differently by bash than the analyzer; commands over 10,000 characters now always prompt instead of auto-running; zsh variable subscripts/modifiers inside `[[ ]]` were being treated as inert text (now prompt); certain `help`/`man` invocations could auto-approve unsafe options or command substitutions (now fixed). Also adds an `EndConversation` tool letting Claude end sessions with abusive/jailbreak users, mirroring claude.ai behavior since 2025.
  Source: https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md
- **GitHub Copilot code review: customization and configurability improvements** (Jul 17) — Copilot code review now runs behind a firewall with custom setup steps and independent runner configuration, and reads custom review instructions from the PR's head branch (not just the base), making instruction changes testable in the same PR that introduces them.
  Source: https://github.blog/changelog/2026-07-17-copilot-code-review-customization-and-configurability-improvements/
