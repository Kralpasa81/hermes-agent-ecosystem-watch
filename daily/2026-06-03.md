## Broader AI agent ecosystem

- **GitHub Copilot SDK is now generally available.** GitHub describes it as a stable, production-ready API for embedding Copilot's agent runtime into apps and developer tools, including planning, tool invocation, file edits, streaming, multi-turn sessions, custom tools, MCP servers, hooks, OpenTelemetry tracing, BYOK, and cloud/remote sessions. Source: https://github.blog/changelog/2026-06-02-copilot-sdk-is-now-generally-available
- **GitHub Copilot added sandbox and automation infrastructure for agentic workflows.** Cloud and local sandboxes entered public preview for safer Copilot execution, while Copilot cloud agent automations can now run scheduled or repository-event-driven tasks in private and internal repositories. Sources: https://github.blog/changelog/2026-06-02-cloud-and-local-sandboxes-for-github-copilot-now-in-public-preview, https://github.blog/changelog/2026-06-02-schedule-and-automate-tasks-with-copilot-cloud-agent
- **Copilot CLI received a high-signal usability/reliability update.** GitHub's June 2 changelog highlights generally available rubber-duck critique, prompt scheduling, and local voice input; the public Copilot CLI changelog also lists version 1.0.59 with process-tree cancellation fixes and HTTP/1.1 as the default transport for reliability. Sources: https://github.blog/changelog/2026-06-02-copilot-cli-improved-ui-rubber-duck-prompt-scheduling-and-voice-input, https://github.com/github/copilot-cli/blob/main/changelog.md
