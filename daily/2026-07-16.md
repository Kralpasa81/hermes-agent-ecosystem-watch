# 2026-07-16

## Hermes / Hermes-adjacent

- No new tagged release today; `v0.18.2` (`v2026.7.7.2`) remains latest, and the curated `v0.19.0` release notes for the post-v0.18.0 window are still pending. Real `main`-branch activity today is multiplex-gateway correctness work, not user-facing features:
  - **Multiplex relay-adapter sharing fix** — in `multiplex_profiles` mode, secondary profiles were starting their own Relay adapter instead of sharing the single process-level Relay ingress the active/default profile already owns. Relay is now explicitly skipped for secondary profiles in multiplex mode (direct, non-binding platforms like Telegram still start normally per profile).
    https://github.com/NousResearch/hermes-agent/commit/2ea39daeb1f675d72e5c21c9400f2d58d7e6d71a
  - **Named multiplex gateway slots kept registered-but-down** — container boot reconciliation was auto-starting named profile gateway slots from their persisted "running" state even when the root/default gateway is already multiplexing every profile, which would spin up duplicate multiplex owners. Named slots now stay registered (for explicit lifecycle control) but do not autostart while `GATEWAY_MULTIPLEX_PROFILES` is set.
    https://github.com/NousResearch/hermes-agent/commit/6a35f9e667ec162489d14856e041f36ee63a12bf
  - **Desktop reasoning-text flash fix** — the Desktop app's reasoning/thinking panel was re-typing from the first character on every streamed delta for token-streaming reasoners (R1/Qwen/GLM/Claude thinking), because a per-part-identity smoothing wrapper reset its reveal state whenever the underlying message part object changed identity. Reasoning text now appends in place, matching how the final answer already streams.
    https://github.com/NousResearch/hermes-agent/commit/c81afd6e504875c8aea10e9423e8b954c5d9fcf7
  - Also landed yesterday (Jul 15, carried forward as context): a compression fallback-timeout fix so slow auxiliary summarization routes get their own timeout budget instead of inheriting the primary's, plus escalating 60s→300s→900s cooldowns on repeat timeout failures — closes a per-turn multi-minute stall on large transcripts (#62452).
    https://github.com/NousResearch/hermes-agent/commit/bd7e4802363d43b5ede42230fc1d65edf8ef80d1

## Broader AI agent ecosystem

- **Codex/ChatGPT Work crossed 8M active users** (announced Jul 14–15) after the GPT-5.6 launch (Jul 9) roughly doubled OpenAI's prior traffic peak within 48 hours. The surge exposed real scaling problems: OpenAI temporarily removed the 5-hour usage cap for Plus/Business/Pro, cut GPT-5.6 Sol's context window back from 372k to 272k tokens after the larger window was draining usage faster than intended, reverted experimental reasoning-effort ("juice") changes, and pushed repeated usage-limit resets — several of which some users report not receiving cleanly (ongoing OpenAI community threads as of Jul 16).
  Sources: https://thenewstack.io/gpt-5-6-codex-user-surge/, https://x.com/thsottiaux/status/2076495156757577895, https://community.openai.com/t/missing-banked-reset-after-codex-usage-limit-reset-announcement/1387097
- **Claude Code `2.1.211`** (Jul 15) shipped mostly security/reliability hardening: new `--forward-subagent-text` flag/env var to surface subagent text and thinking in stream-json output; permission-preview messages relayed to chat channels are now sanitized against bidirectional-override, zero-width, and look-alike quote characters so tool inputs can't visually spoof an approval prompt; auto mode can no longer override a PreToolUse hook's `ask` decision for unsandboxed Bash; a prompt-caching regression on Bedrock/Vertex/Mantle/Foundry that billed the trailing system context block as fresh input tokens on every request is fixed.
  Source: https://raw.githubusercontent.com/anthropics/claude-code/refs/heads/main/CHANGELOG.md
