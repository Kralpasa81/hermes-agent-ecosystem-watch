# 2026-07-30

## Hermes / Hermes-adjacent

- **iMessage-style message reactions land as a real cross-cutting capability.** Reactions now have full-stack support: they live in the existing `messages.display_metadata` JSON column (no new table), with iOS Tapback semantics enforced DB-side (one reaction per author per message, re-tap retracts, a different emoji replaces). A new `message.react` RPC, a desktop-gated `react_to_message` agent tool, and clean model-context handling (reactions ride `run_message` only, so the persisted prompt and cached prefix never change) round it out. Desktop ships the UI to match: a tapback pill, a `frimousse`-based emoji picker, `:shortcode:` completions in both composers, and live paint — catching up to the reaction contract five platform adapters already shipped, and off by default under Settings → Appearance.
  https://github.com/NousResearch/hermes-agent/commit/7d92056c49, https://github.com/NousResearch/hermes-agent/commit/6ec319f530, https://github.com/NousResearch/hermes-agent/commit/a90ccd46b7, https://github.com/NousResearch/hermes-agent/commit/fec1ac0a7a
- **A real voice-mode regression is closed: `voice_only` no longer leaks into text replies.** `adapter_auto_tts` was unconditionally widening `_should_send_voice_reply`, so a chat explicitly set to `voice_only` could still get a spoken reply to typed text input (regression tracked as #73508). Fixed so the chat-level `all`/`voice_only`/`off` choice is always authoritative, with `adapter_auto_tts` acting only as a fallback when no explicit mode is set.
  https://github.com/NousResearch/hermes-agent/commit/0bf471dd68
- **Several concrete native-Windows correctness bugs are closed**, salvaged from a stalled community PR (#57016): `file:///C:/...` drive-letter URIs were mis-parsed, backslash-vs-forward-slash separators could defeat profile-ownership detection in gateway status, `cprint` crashed instead of degrading on consoles with no `prompt_toolkit` screen buffer, and WSL `/mnt/c/...` browser paths could pick up backslashes and break. All four are now fixed with dedicated regression tests.
  https://github.com/NousResearch/hermes-agent/commit/53f7d137ed
- **Desktop gains an "Open Folder as Project" workflow.** `⌘O` and a new `File > Open Folder…` menu item both route into `openFolderAsProject`: pick a folder, land in the project that already owns it or create one named after the folder, scope the sidebar, and open a fresh session there. The command palette (`⌘K`) also gained a Projects group for fast project switching.
  https://github.com/NousResearch/hermes-agent/commit/5affcd6bf4, https://github.com/NousResearch/hermes-agent/commit/a11611af39, https://github.com/NousResearch/hermes-agent/commit/ba194c1d19
- No new tagged release since **v0.19.0 "Quicksilver"** (Jul 20); today's remaining commit volume is desktop UI/perf polish (composer-paste directive chips, checkbox indeterminate state, sidebar icon-clip fix, command-palette perf, tab-title/OSC handling) rather than further capability work.

## Broader AI agent ecosystem

- **GitHub Copilot's code review support for agent skills and MCP servers reaches general availability** (Jul 29, previously public preview) across Pro, Pro+, Business, and Enterprise. `SKILL.md` files under `.github/skills` can now feed team-specific standards into every review, and any MCP servers already configured for Copilot cloud agent automatically apply to code review too (tool calls are read-only there); comments now show attribution when they came from a skill or MCP context. A concrete mainstream productization of MCP + agent skills, not just a spec update.
  https://github.blog/changelog/2026-07-29-copilot-code-review-agent-skills-and-mcp-now-generally-available
- **GitHub introduces a default model-enablement policy for Copilot Business/Enterprise** (Jul 29): going forward, newly-GA models are on by default for these plans instead of requiring per-model admin opt-in, with a single org/enterprise-level opt-out. The policy is inert for 28 days (until Aug 26) before taking effect; explicit existing per-model choices are preserved, and open-weight/non-DPA models (e.g. DeepSeek, Kimi K2.7, Fable 5) stay excluded regardless of policy.
  https://github.blog/changelog/2026-07-29-default-model-enablement-for-copilot-business-and-enterprise
- No new stable Claude Code release since `2.1.220` (Jul 25); OpenAI Codex CLI remains in alpha churn past stable `0.146.0` (latest: `rust-v0.147.0-alpha.2`, Jul 30) with no user-facing changelog yet worth reporting.

## New / notable tools and platforms

- **Hermes message reactions** (see above) is today's most complete new capability: a full storage/RPC/tool/model-context stack plus a matching desktop UI, bringing desktop to parity with five platform adapters that already supported reactions.
- **Hermes desktop's "Open Folder as Project"** workflow (`⌘O`, File menu, command palette) is a genuine project-management UX addition worth tracking as desktop's project model matures.
- **GitHub Copilot code review's GA of agent skills + MCP** is worth tracking as a concrete, large-surface-area adoption point for MCP outside of pure dev-tool contexts.

## Note

Bugün ne Hermes tarafında ne de daha geniş ekosistemde dünkü ölçekte bir gelişme yok (dün MCP 2026-07-28 spec'i canlıya alınmıştı ve Hermes streaming TTS gibi büyük bir özellik gelmişti); ama bugün de gerçek, doğrulanmış içerik var. Hermes'te en dikkat çekici değişiklik iMessage tarzı mesaj reaksiyonları: storage, RPC (`message.react`), agent tool (`react_to_message`) ve model-context tarafı (reaksiyonlar sadece `run_message`'a biniyor, persisted prompt ve cache prefix hiç değişmiyor) tam bir yığın olarak geldi; desktop UI (tapback pill, emoji picker, `:shortcode:` completions) bunu tamamlıyor ve zaten 5 platform adapter'ında var olan reaksiyon sözleşmesine yetişiyor. Ayrıca gerçek bir regresyon kapatıldı: `voice_only` modunda yazılı girişe sesli yanıt verilebiliyordu (#73508), artık chat seviyesindeki mod her zaman öncelikli. Bir topluluk PR'ından (#57016) kurtarılan dört gerçek native Windows düzeltmesi de var (drive-letter URI, path separator, konsol banner fallback, WSL browser path). Yeni bir sürüm etiketi yok (v0.19.0 "Quicksilver" hâlâ Jul 20'den itibaren en güncel), geri kalan commit hacmi büyük ölçüde desktop UI/performans cilası. Broader ecosystem'de bugünün en gerçek gelişmesi GitHub Copilot code review'ın agent skills + MCP desteğinin GA'ya çıkması (Jul 29) — bu MCP'nin dev-tooling dışında geniş ölçekli, gerçek bir üretim ortamına girdiğinin somut bir göstergesi. Ayrıca GitHub, Business/Enterprise için varsayılan model etkinleştirme politikası tanıttı (28 gün sonra, 26 Ağustos'ta devreye girecek) — yönetişim açısından not edilmeye değer ama bugün etkisi yok. Claude Code'da `2.1.220`'den (Jul 25) yeni bir şey yok; OpenAI Codex CLI stabil `0.146.0`'ın ötesinde hâlâ alpha aşamasında (`0.147.0-alpha.2`, Jul 30) ve henüz raporlanmaya değer bir changelog yok.
