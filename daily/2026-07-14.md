## Hermes / Hermes-adjacent

- **Nous Research (Hermes' maker) reportedly in talks for a new funding round at a $1.5B valuation** — raising at least $75M led by Robot Ventures, with significant participation from USV and other investors, according to TechCrunch sources. This would be a large step up from the company's prior $70M total raised (Paradigm, Robot Ventures, North Island Ventures, OSS Capital, Balaji Srinivasan). Sources say the new funding would help expand Hermes' products and business model. No official confirmation from Nous Research yet. No new tagged Hermes Agent release since **v0.18.2 (v2026.7.7.2)**, July 7; v0.19.0 curated release notes are still pending.
  Source: https://techcrunch.com/2026/07/13/hermes-agent-maker-nous-research-in-talks-for-new-funding-at-1-5b-valuation/

- Real correctness fixes continued landing on `main` (Jul 13–14), hardening dashboard/Desktop/Windows surfaces:
  - **Dashboard: `memory.provider` restored to the config schema (#63886)** — an earlier memory-provider UI rework had stripped `memory.provider` from `/api/config/schema` server-side; since Desktop's settings page builds its field list from that schema, the Memory Provider dropdown had silently vanished from Desktop after v0.18.1. Fixed by restoring the select with dynamically discovered provider options.
    https://github.com/NousResearch/hermes-agent/commit/861d69c7bba8d2ea6a1cd170e989c901c74d32d1
  - **Windows: Git Bash coreutils now placed on PATH for the non-login shell fallback (#64042)** — a prior fix (#63955) let Hermes survive a broken login shell by falling back to non-login `bash -c`, but that fallback never sourced `/etc/profile`, so `cat`, `mv`, `mktemp`, `chmod`, `find`, and other coreutils used by file/terminal tools were missing from PATH — silently producing `bytes_written:0` on writes and exit code 127 on terminal commands. Git Bash's bin dirs are now derived and prepended in the correct precedence order.
    https://github.com/NousResearch/hermes-agent/commit/4a58e22e997ec56802fa93d4ca503a3767a02c4a
  - **Desktop: cross-platform builds no longer stage the wrong-architecture `node-pty` binary** — packaging previously copied the host's native `node-pty` build even when targeting a different OS/arch (e.g. staging a macOS binary into a `linux-arm64` build); builds now fail closed on mismatched targets and validate staged binaries by magic bytes.
    https://github.com/NousResearch/hermes-agent/commit/7a44a8fdec45cb27ee6f8c24470bdfa6a17272ce
  - **Desktop: reasoning text now renders correctly in the Thinking widget (#63999)**.
    https://github.com/NousResearch/hermes-agent/commit/19641fab72fd91dadb54148001a48d0fecf8554d

- These remain unreleased `main`-branch fixes ahead of v0.19.0; worth tracking since they resolve real cross-platform installer, packaging, and Desktop config-surface bugs.
