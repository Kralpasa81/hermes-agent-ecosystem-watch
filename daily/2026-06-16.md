# 2026-06-16

## Hermes / Hermes-adjacent

- **Hermes Agent still has no newer tagged release after `v2026.6.5` / v0.16.0, but June 16 main-branch activity produced several practical Desktop, remote-gateway, and delegation fixes.** Source: https://github.com/NousResearch/hermes-agent/releases/tag/v2026.6.5
- **Remote-gateway Desktop flows were tightened.** Hermes now opens remote-gateway artifacts through authenticated download, and routes global remote-profile REST calls correctly. These are important follow-ups for the Surface-release model where a local Desktop can control a remote Hermes runtime. Sources: https://github.com/NousResearch/hermes-agent/commit/c6b0eb4de0e5010a752e312c0577a4d04d2a08a5, https://github.com/NousResearch/hermes-agent/commit/0441b7f19feb9f1fdd9aac2af8cf022f1b50b174
- **Dashboard update controls were made more environment-aware.** June 16 commits hide update controls for hosted dashboards and detect/simplify containerized dashboard update management, reducing the chance that browser-admin UI exposes update actions that do not apply to the running deployment shape. Sources: https://github.com/NousResearch/hermes-agent/commit/0b6b29a30cb40dd53fd5f8d28fec6d4ee1ebd4ff, https://github.com/NousResearch/hermes-agent/commit/b1d6a578832dadc9ef3ba1a591e5ea8bebd7d568, https://github.com/NousResearch/hermes-agent/commit/7cd71de1f45b060b1404b2f0c5bf4cb4305dd716
- **Desktop session UX continued to mature.** Hermes added compact new-session windows, trimmed scratch-window chrome, and synced new sessions across windows. Sources: https://github.com/NousResearch/hermes-agent/commit/98c294126bafb2ba5660a2dc817c97e7dc8c95bf, https://github.com/NousResearch/hermes-agent/commit/0f75e9904a8f9838a706a0cf84b01bc4576b368a, https://github.com/NousResearch/hermes-agent/commit/67233d1c2ad5e6770eec6684fa32cba3ce7c0f60
- **Delegation reliability improved for asynchronous work.** `delegate_task(background=true)` now forwards the background flag so delegated tasks can actually run asynchronously. Source: https://github.com/NousResearch/hermes-agent/commit/0a8f3e21b8085f24d1dafba6c34911d87b756cfb

## Broader AI agent ecosystem

- **OpenAI Codex CLI `0.140.0` was published as a stable release on June 15 and surfaced as a strong June 16 signal.** Notable changes include `/usage` views, better `/goal` preservation for large text and image attachments, permanent session deletion, `/import` from Claude Code, unified `@` mentions for files/plugins/skills, managed Amazon Bedrock API-key auth, encrypted local storage for CLI and MCP OAuth credentials, automatic SQLite state rebuilds, and MCP startup/OAuth reliability fixes. Sources: https://developers.openai.com/codex/changelog, https://github.com/openai/codex/releases/tag/rust-v0.140.0
- **Claude Code `v2.1.178` is a high-signal reliability and governance release.** It adds `Tool(param:value)` permission rules, nested `.claude/skills` loading, closest-directory precedence for agents/workflows/output styles, classifier review before subagent launch in auto mode, better Remote Control error visibility, multiple subagent/background-session fixes, fallback-model compaction fixes, and corrected MCP server-level `disallowedTools` handling for subagents. Source: https://github.com/anthropics/claude-code/releases/tag/v2.1.178
- **GitHub Actions began the Node 24 default-runtime migration on June 16.** This is relevant to automation and agentic CI because JavaScript actions now begin moving from Node 20 to Node 24 by default; maintainers should update action metadata and users should update workflow dependencies, with only temporary opt-out support for Node 20. Source: https://github.blog/changelog/2025-09-19-deprecation-of-node-20-on-github-actions-runners
- **GitHub Copilot enterprise usage metrics now include server-side telemetry in addition to client-side signals.** This can raise DAU/active-user totals and make reporting closer to billing/activity reality, though detailed breakdowns may remain empty for server-side-only detections. Source: https://github.blog/changelog/2026-06-15-copilot-usage-metrics-now-include-more-of-your-active-users
