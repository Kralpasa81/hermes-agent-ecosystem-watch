- **MCP 2026-07-28 release candidate** — directly relevant to Hermes users and skill/tool authors.
  - The largest MCP spec revision since launch. Key changes: stateless HTTP core (no more session IDs or sticky routing), MCP Apps (server-rendered UIs), Tasks extension, OAuth/OIDC-aligned authorization, JSON Schema 2020-12 for tools, formal deprecation policy.
  - Impact for Hermes: MCP servers used by Hermes (including custom skills and tools) will need to target the new stateless model. The stateless core removes the need for sticky sessions and shared session stores — a meaningful infra simplification for self-hosted Hermes deployments using MCP.
  - Final spec ships **July 28, 2026**. RC is locked; this is the validation window.
  - Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/

## Broader AI agent ecosystem

- **MCP 2026-07-28 RC** is the headline ecosystem item this week (see above). The stateless protocol change removes `initialize`/`initialized` handshakes and `Mcp-Session-Id`, making any MCP server instance capable of handling any request. Load balancers, gateways, and rate-limiters can now route on `Mcp-Method` headers without deep packet inspection. `ttlMs`/`cacheScope` on list results replaces SSE keep-alive as a freshness mechanism. These changes require updating SDK-level client code; Tier 1 SDKs are expected to ship support before July 28.
  - Source: https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
