### Hermes Agent
- Area: open-source agent framework
- Why it matters: primary watch target for releases, docs, gateway, tools, cron, skills, MCP, and workflow changes
- Current watch note: **v0.19.0 / v2026.7.20 — "The Quicksilver Release"** (tagged Jul 20, 2026) remains the latest tagged release; post-release stabilization continues through Jul 29 with no version bump yet. Headline changes at release: **~80% cold-start first-token latency cut** (CLI/gateway/TUI/desktop/cron, ~4.3s → ~0.9s) plus reasoning-stream-by-default; **smart approvals** on by default; **Bitwarden and 1Password `SecretSource`** integrations; live subagent transcripts and durable background-delegation delivery; gateway **delivery-obligation ledger**; **/subscription + /topup** terminal billing; **profile-based gateway message routing**; new models (GPT-5.6 Sol/Terra/Luna, grok-4.5 GA, kimi-k3, claude-fable-5, claude-sonnet-5); and a major desktop speed/security hardening round. Post-release stabilization (Jul 21–27): stranded-platform gateway recovery, clarify-request lifecycle unification, cross-session isolation fixes, a crash-survivable in-flight turn journal, a root-caused SQLite corruption bug in `hermes sessions optimize`, a `hermes update` cryptography-pin downgrade bug, a gateway-hang class in `delegate_task`, and a desktop "Artifacts" pane for versioned/previewable generated content. **Jul 28**: a real MCP interoperability gap with Figma's OAuth allowlist is closed (Hermes 403'd where Claude Code/Codex worked, now verified with 26 tools); desktop ships floating panes and a floatable composer with a new `FloatingAnchor` SDK hook for plugins; a gateway race that made queued messages sometimes misbehave as live-turn steers/interrupts is closed; and an opt-in NeMo Relay observability integration was merged, caught causing an Anthropic streaming regression, and reverted within 24 minutes (fix PR open, not yet merged) — a good catch-and-revert signal, not a shipped user-facing regression. **Jul 29**: streaming TTS becomes a real cross-provider capability — a new opt-in adapter seam on `BasePlatformAdapter` lets voice-capable platforms (LiveKit, Discord voice) consume streaming PCM audio, cutting perceived voice latency ~2–3.5s → ~500–800ms, with Gemini/xAI streaming providers added alongside ElevenLabs/OpenAI and a new `tts.streaming.provider` knob; voice mode's stop-phrase handling closes a real gap where a spoken stop phrase could be silently discarded (conversation never ends) and typed stop phrases weren't caught at all — now consistent across CLI/TUI/desktop, spoken and typed; STT becomes fully configurable (GUI dropdowns, OpenAI `gpt-transcribe` support, a faster-whisper silence-hallucination fix); the dual-stack webhook bind fix (previously LINE-only) is extended to WeCom/MSGraph/WhatsApp Cloud/Teams/Telegram; and the Hermes×Buzz (Nostr) integration reaches a documented three-path state (Desktop managed runtime, `buzz-acp` relay bridge, native gateway platform) with a dependency-free Nostr signing module and a WebSocket inbound transport.

- Current watch note: **`2.1.219`** (Jul 24) sets **Claude Opus 5** as the default Opus model — 1M context, fast mode at $10/$50 per Mtok (Opus 4.7 removed from fast mode) — same day GitHub Copilot shipped Opus 5 across nine surfaces, making this a genuine cross-vendor model-launch event rather than a routine bump. ### MCP ecosystem
- Area: protocol / tool interoperability layer
- Why it matters: increasingly central to connecting agents with external tools and services
- Current watch note: **The MCP 2026-07-28 specification has gone live (confirmed Jul 29).** `modelcontextprotocol.io/specification/latest` now 307-redirects to `/specification/2026-07-28` — as of the Jul 28 check it still pointed at `2025-11-25`. This is the largest spec revision since launch: stateless HTTP core (removes `initialize`/`initialized` handshake and `Mcp-Session-Id` — any server instance can handle any request, works behind a plain round-robin load balancer); MCP Apps (server-rendered UIs via a new extension); Tasks extension now first-class; OAuth/OIDC-aligned authorization; JSON Schema 2020-12 support for tool schemas; W3C Trace Context propagation standardized; `ttlMs`/`cacheScope` on list results; formal deprecation policy (12-month window minimum). This is a confirmed **breaking change** for existing MCP implementations — client/server maintainers should check compatibility now that it's live rather than pending. **Jul 23: GitHub MCP Server shipped concrete stateless-core support ahead of the deadline** — Redis-backed sessions removed entirely (no DB writes on `initialize`, no DB reads per call), deep packet inspection replaced with guaranteed HTTP-header fields for logging/secret-scanning, and its stdio elicitation flow upgraded to the new multi-round-trip HTTP elicitation with a Go SDK compatibility wrapper for old/new clients. Tier 1 SDKs have all shipped backward-compatible beta support; official conformance tests were also added. Enterprise-Managed Authorization (centralizing MCP server access through an IdP) remains stable. **Jul 28: Hermes closed a real MCP OAuth interoperability gap with Figma** (see Hermes Agent entry) — a concrete example of the practical friction MCP clients hit against provider-specific OAuth allowlists.
- Sources: https://modelcontextprotocol.io/specification/2026-07-28, https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/, https://github.blog/changelog/2026-07-23-github-mcp-server-supports-the-next-mcp-specification/, https://github.com/NousResearch/hermes-agent/commit/1eb5ee1e
